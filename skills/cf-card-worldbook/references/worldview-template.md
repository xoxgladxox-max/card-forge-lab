# world 节点模版：`worldview_profile`

`world` 节点正文参考本模版组织。动笔前先写出常驻边界与分层判断，提出结构提案（启用哪几层、保留哪些子模块、是否拆分子节点），作者确认后再动笔。

顶层包裹 `<world name="世界名">` … `</world>`；地点、物种与设定、法则、器物分别采用 `<location name="…">`、`<lore name="…">`、`<rule name="…">`、`<item name="…">`。内部为结构化 YAML：骨架层级 key（`worldview_profile`、`base_world`、`core_systems` 等）用英文，具体条目以事物本名作 key，下一层按该事物自身的方面展开。

本文件中的示例借用「娘化宝可梦世界」说明字段写法，实际制卡时按当前作品背景重写。

## 先定用哪几层

| 题材来源 | 启用层级 | 说明 |
|---|---|---|
| 原创世界 | `world_foundation` + `base_world`；有全线专属法则时加 `core_rules` | 完整建立世界运转基底 |
| 已知作品正传 | `world_foundation` + `base_world` | 熟悉背景适度精炼，决定世界运转的关键项完整保留 |
| 已有作品衍生 / IF / 特异二创 | `world_foundation` + `base_world` + `if_divergence` + `core_rules` | 按「原作基底 → 分支差分 → 核心法则」顺序依次构建 |

## 框架字段归属

| 框架字段 | 归属节点 |
|---|---|
| `prototype`、`setting_type`、`era`、`culture`、`tone` | `world`：`world_foundation` |
| `world_history`、`world_location`、`social_structure`、`special_groups`、`core_systems`、`environment_features` | `world`：`base_world` 或 `if_divergence` |
| 全线专属法则（法则本名作 key） | `world`：`core_rules` |
| `narrative_rules`、`style_tags` | `style` 节点 |
| `core_gameplay`、`core_drive`、`core_experience` | 规划清单与 `output` 节点 |
| `protagonist_focus`、`key_characters` | 规划清单与 `character` 节点 |

## 骨架

```yaml
worldview_profile:
  world_foundation:
    prototype:          # 依托的原作及本卡所处位置；原创世界写一句核心定位
    setting_type:       # 题材类型
    era:                # 时代背景与技术或修行水平
    culture:            # 社会风貌与文化底色
    tone: |             # 这个世界寻常日子的生活质感

  # ── 第一层：基底，原作世界的完整常态 ──
  base_world:
    world_history:      # 仍在影响当下格局的正史、民间传说与旧例
      <事件名>:
        <方面>: <留存至今的格局或规矩>
    world_location:     # 地域版图与各方地缘关系
      <地名>:
        <方面>: <地理职能与现状>
    core_systems:       # 修行、科技、异能等基础世界系统
      <系统名>:
        <方面>: <成立条件、实际效果与限度>
    special_groups:     # 族群、物种、主要势力与一般生理生态
      <群体或物种名>:
        <方面>: <生理特征、习性或组织方式>
    social_structure:   # 社会秩序、生计方式与日常礼俗
      <制度或阶层名>:
        <方面>: <运作方式与现实处境>
    environment_features:   # 自然环境有独特规则时启用
      <现象名>: <环境特征与影响>

  # ── 第二层：差分，分叉点之后的变迁 ──
  if_divergence:
    world_history:      # 分叉事件与随后演进的大势
      <事件名>:
        <方面>: <分叉后的新局面>
    social_structure:   # 分叉后的秩序调整与风气变化
      <制度或阶层名>:
        <方面>: <与基底相比产生的新变化>
    special_groups:     # 新兴或改组的势力与群体
      <势力名>:
        <方面>: <当前定位与动向>
    world_location:     # 新增或发生剧变的核心地界
      <地名>:
        <方面>: <当前面貌与职能>

  # ── 第三层：法则，全线生效的世界级规则 ──
  core_rules:
    <法则名>:           # 客观结算规则写清触发条件、效果、限度与可逆方式；概念氛围规则写一句核心方向，应验形态留白
      <方面>: <当满足某条件时产生的结果及适用范围>
```

示例（娘化宝可梦世界）：

```yaml
core_systems:
  精灵球:
    收服: 野生个体体力越低越容易收服；已登记在训练家名下的个体受联盟协议保护，只响应原主人的精灵球。
    球内休养: 处于球内时暂停饥饿与伤势恶化；连续在球内停留满三天后，出球初期会有短暂的方向感迟钝。
    归属流转: 球体编号登记在联盟名册，正式转让需双方前往宝可梦中心办理变更登记，方可继续使用中心医疗设施。
special_groups:
  娘化宝可梦: 人形外貌下完整保留原本的属性体质与招式本能，对战中的属性相克照常生效。
```

## 填写准则

- **四状态清晰标注**：子模块随题材按需启用；每个字段对应 **有料**（正常填写）、**原作无记载**（如实写明）、**缺口**（标【缺口】并列入查料单）或 **确认精简**（经作者确认后移除）。
- **事物本名作 key**：直接以事物名称作为键名，下一层展开该事物自身的运作方面（如「收服」「球内休养」「归属流转」），省去空泛的 `name / definition` 套娃槽位。
- **聚焦当下有效信息**：往事转化为仍在影响当下的规矩、格局或隐患；与常识一致的背景用一句话精炼带过，遇到「只写半句会导致模型在日常场景猜错」的关键机制则完整展开。
- **本土化自然命名**：把现代二次元或外来标签概念转化为契合本世界时代与文化的本土名称，通俗叫法留给世界书条目的 `keys` 负责触发。
- **开放条件替代排他死锁**：描述破局手段、收服或晋升条件时，使用「当……时」「可通过……或……达成」等正向条件句，给玩家和剧情留出合理变通余地。

## 上下位拆分与专项条目写法

| 内容性质 | 归属位置 | 触发配置 |
|---|---|---|
| 全线通用底子、各子类的上位泛用分类与一句核心定位 | 上位世界总纲（`world` 常驻主条目） | `constant: true`（双向关递归，零绿灯专名） |
| 简短且全线通用的基础背景 | 留在上位总纲对应模块内 | 随总纲常驻 |
| 同类并列短设定较多 | 打包为 1 条下位「同类合集条目」 | 绿灯（`keys` 填各项专名） |
| 需深入展开的物种、器物术法、核心习俗或局部地点 | 性质相异的概念各自独立成 1 条下位专项条目 | 绿灯（按专名与通俗别名触发） |

### 三类常见下位专项条目的定制写法

根据条目所写事物的真实性质组织结构，避免把同一种流程模板硬套到所有条目上：

1. **特殊物种与族群（`lore`）**：
   - 合并呈现完整的客观生理硬件与泛用生态习性：写清形体与体征底线（如体温、呼吸心跳有无、感官特长、存续食粮）、日常栖息与群体本能，再用「有时…一些个体…在特殊情况下…」补充面对外人或特殊刺激时的常见反应方向。单角色的独门绝活归入其 `character` 条目。
2. **器物、法器与术法（`item` / `lore`）**：
   - 先立正统上位功能：写明该器物或术法在修行、护身、镇压、医治或日常礼制中的本职功用、使用步骤与消耗限度；再将私下变通、借物传情或欢好助兴等衍生用法放入「有时…一些人…在特殊情况下…」的开放举例中。
3. **社会风俗与专门互动（`rule` / `lore`）**：
   - 按自然顺序展开四块：**是什么与日常规矩**（社会定位、适用关系与边界） → **标准过程怎么做**（准备、接触到收束的自然步骤） → **常见细节与个体差异**（用「有时…一些人…还有一些人…例如…在特殊场合下…」写出自然反应与小心思） → **描写关注点**（视角、感官与环境氛围）。

## 分工边界：世界管客观格局，角色管个体人生

| 情形 | 归入 `world`（客观世界现象） | 归入 `character`（个体角色档案） |
|---|---|---|
| 势力首领 | 「火箭队在关都地区借走私与地下交易扩张势力，首领为坂木。」 | 坂木本人的性格城府、对猫老大的偏爱、个人往事与说话口吻 |
| 物种通性与个体癖好 | 「娘化宝可梦保留原属性与招式本能，体力透支时自动收回精灵球休眠。」 | 某只皮卡丘被捏脸颊时气鼓鼓放电的个人小习惯 |
| 全局法则与个人反应 | 「契约缔结后双方共享痛觉，任一方重创时另一方同步承受冲击。」 | 某位训练家初次承受共享痛觉时咬牙忍住不吭声的个人表现 |
| 异乡来客与主角处境 | 「近年各地偶有来历不明的异乡人现身，联盟对其建立登记观察制度。」 | 主角个人的具体性格、随身物品与某条开局路线的起手处境 |
