# 篇章生成器模板

首条开场白写成篇章生成器：一段原文引子，加一个 yaml 选择器，让玩家自己选从哪个开局开始、扮演谁，AI 从那一刻开始写。

## 什么时候用

如果卡有两条以上不同的开局，或者玩家可以选扮演哪一方，那么 `first_mes` 用篇章生成器。只有一个开局、玩家身份固定的卡不用。

## 结构

从上到下：

1. **引子**：原作开篇或和本卡基调相合的一段原文，逐字截取，要求同「用原文开场」。原作里有分隔符的可以照用。没有合适原文时照原文风格自写，并在节点里标明是自写。
2. 分隔线 `---`。
3. **选择器标题**。
4. **一两句说明**：填好哪几栏、回复给叙事者，叙事者按选择设好时间、地点和在场的人，从那一刻开始。
5. **yaml 代码块选择器**。
6. 到此结束。代码块之后不补收尾句或引导句。

## 选择器怎么写

- 选择栏放在代码块最上面，冒号后留空。不预填，不给默认视角，由玩家自己选。
- 篇章栏：每个篇章对应一条备选开场白，编号、名称和备选一一对应；最后加一项「自定义」，让玩家写明时间、地点和在场的人。
- 每个篇章写四行：时间、地点、在场、起点。起点写这一场从哪一刻开始，只写局面，不写结果。
- 如果卡允许玩家选扮演哪一方，那么加视角栏，写明「你扮演谁；叙事者扮演另一方和其余所有人」；否则只留篇章栏。
- 篇章的时间、地点、起点都要有出处，要求同「前提要有出处」。
- 说明性的文字写成 yaml 注释（`#`），不写成要填的字段。

## 骨架

例，照本卡改写：

````text
【原作开篇原文，逐字截取】

---

### 【作品名 · 篇章选择器】

请在下方填好篇章和视角，回复给叙事者。叙事者会按你的选择设好时间、地点和在场的人，从那一刻开始。

```yaml
【选择篇章】：
【选择视角】：

# 篇章（填编号或名称）
# 1.【篇章名】
#    - 时间：
#    - 地点：
#    - 在场：
#    - 起点：
# 2.【篇章名】
#    - ……
# N.【自定义】
#    - 写明时间、地点和在场的人

# 视角（你扮演谁；叙事者扮演另一方和其余所有人）
#    - 角色甲
#    - 角色乙
```
````

## 配套

- 首条让给生成器，原来最有代表性的开局挪到第一条备选。
- 玩家回复选择时，AI 看不到备选开场白的正文。卡的输出规范里要写一句：收到篇章选择后，从所选篇章的起点写第一场，格式照输出规范，不照选择器。
- 生成器里不放状态栏。卡有状态栏时，初始状态栏放在各条备选末尾，以及玩家选完后的第一场回复里。
