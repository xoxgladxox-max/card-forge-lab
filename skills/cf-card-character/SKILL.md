# 角色卡构建器（v3.12.0）

范围：角色泛化设定本体、附加模块（`module`）、过往事件（`lore` / `module`）和独立语料节点（`corpus`）怎么写、写到哪一关停。只建卡，聚焦结构与内容构建。

| 当前任务 | 参考文件 |
|---|---|
| 写 YAML、查泛化本体与条件语料拆分 | `references/template.md` |
| 挑选性格、外貌、体质与偏好标签 | `references/era-traits.md` |
| 写 R18 泛化生理设定与独立亲密语料块 | `references/nsfw.md` |

## 动笔前置闸门：两原则一问题

每个单元动笔或修改前，先逐项完成以下三步自检，再进入正文撰写：

1. **原则 1（写出明确判断与角色卡预测输出方向）**：先用两三句话写出明确判断，说明这组设定属于全场景通用的泛化规律还是按需触发的具体语料，并写出**角色卡预测输出方向**（在两三种典型互动场景下，这组设定会引导模型产出怎样的反应基调与演进方向）。
2. **原则 2（排查死板套路，给模型留出自由发挥空间）**：逐项检查是否把单次动作、固定原话或线性反映公式塞进了泛化设定本体；凡是换一个场景就不再成立的具体台词、微动作切片与单次事件，统一移入下位条件绿灯节点。
3. **一问题（缺信息立即停下向作者提问）**：自检「当前是否还缺乏关键信息（人物核心动机、声线调性、过往因果、体验方向或角色卡预测输出方向）？」。只要存在影响人物立住或偏离体验方向的未知项，当场停下，向作者列出所缺信息、逐步请作者补充或确认体验方向与角色卡预测输出方向，待信息齐备后再写完整内容。

## 总规则

- **泛化设定本体与具体语料节点严格物理分离**：酒馆将常驻与前置设定拼入高权重系统提示词，混入具体台词和微动作会让高依从度模型逐句照抄。因此角色工程物理拆为两类文件：
  - **泛化设定本体（`lorebooks/character/<角色名>.md`）**：只写任何场景都能成立的底层身份、认知功能机制、性格处事原则、静态外貌感官、说话习惯规律（自称、称呼切换规则、句长节奏、用词偏好）、关系心理定位、过往经历对当下性格的泛化因果（`past_shaping`），以及 R18 客观生理硬件、技艺档位与态度底线（`sexual_information`）。本体保持零具体台词原句、零单次分镜小动作、零单次具体事件剧本。
  - **具体语料与事件节点（独立条件绿灯 `constant: false`）**：具体原话样本、微动作切片、情境问答（`character_qa`）拆入 `<角色名>语料.md`（`type: corpus`，`<character name="…" part="语料参考">`）；单次具体过往事件拆入 `<角色名>过往事件.md`（按事件或旧地关键词触发）；具体亲密动作与床笫台词拆入 `<角色名>亲密表现.md`（`type: module`，`<character name="…" part="亲密表现">`）。每个语料类节点首行写明正面校准说明：「以下样本用于校准角色声线、句长与情绪刻度，正文中顺着当前情境与角色本我生成全新的台词与动作」。
- **证据与层级优先**：每个原作事实都能追到料源或作者确认；旧稿只作检索线索，可选设计标为【提案】，关键信息待补时按「一问题」停下向作者提问确认。
- **单点归属与职责清晰**：角色卡只写该角色独有的身份、外貌、认知机制、说话规律、专属机制与个人反应。世界书已有的公共体系、通用法则或物种通性由对应世界书条目承担，角色卡直接写这个人在其中的个人处境与取舍规律。
- **按人物立住为准**：字段数量与篇幅服从角色辨识度，性格、外貌与互动优先使用现成概念与圈内通用 tag，作者沟通时的比喻只提炼背后的运作条件与限度。
- **按文本类型划分工程区域与单角色三步任务方案**：

| 单元 | 前置判断与当前任务 | 只读范围 | 只写范围 | 文体要求 |
|---|---|---|---|---|
| **Unit 1 泛化内核与静态锚点** | 执行两原则一问题，确认体验方向与预测输出方向；填写 `basic_settings`、`overview`、`appearance`、`sensory_details`、`personality`、`speaking_style`（仅规律）、`persona.past_shaping`、`relationships`（仅泛化定位与互动原则）、`sexual_information` | 世界总纲 + `记录/调研/char-<角色名>-档案与判型.md` | `lorebooks/character/<角色名>.md` 泛化静态与人格段 | **全场景泛化说明文体**：写清任何场景通用的底层因果与客观特征，保持日常常态净室边界与零原句台词 |
| **Unit 2 随境原则、专属机制与条件事件/亲密块** | 执行两原则一问题，切分跨场景处事原则与特定条件模块；填写本体 `clothing`、`behavior_logic`、`decision_making_style`、`conflict_behavior`、`about_xxx`，并按需拆分 `<角色名>过往事件.md`、阶段 `module` 与 `<角色名>亲密表现.md` | 同上 + 对应规则分包 `rules-*.md` | `lorebooks/character/<角色名>.md` 原则段，及独立条件绿灯 `module` / `lore` / `event` 文件 | **泛化原则 + 条件光谱文体**：本体写跨场景原则与开放方向；具体往事与亲密动作归入各自条件绿灯 |
| **Unit 3 独立条件绿灯语料节点** | 执行两原则一问题，写出声线、句长与情绪刻度判断；将代表性纯台词、微动作切片与 `character_qa` 写入独立条件绿灯语料文件 | `记录/调研/char-<角色名>-台词语料.md` + 已确认的角色泛化本体 | `lorebooks/character/<角色名>语料.md`（`type: corpus`，`constant: false`） | **纯自然口语与情境切片文体**：顶行写明声线校准与现场重写说明，内部收录贴合人物呼吸的纯口语样本 |

  - 每次专注处理 1 个角色，跑完一个单元即可单独审阅调整，确认后再推进下一位角色。

## 输出格式与常态边界

- 角色泛化本体包裹在 `<character name="人物名">` 内，英文 key，中文 value，尾部保留简短的 `roleplay_tips` 扮演提示；独立语料、回忆与亲密节点包裹在 `<character name="人物名" part="语料参考/过往事件/亲密表现">` 内。
- 落盘为 `lorebooks/character/*.md` 时采用标准 YAML Frontmatter：头部 `--- ... ---` 写触发属性，下方直接接 `<character ...>` 正文（工具同时兼容含 `<!-- body -->` 的旧节点文件）。
- **日常块保持常态净室边界**：`basic_settings`、`overview`、`personality`、`relationships`、`persona` 等日常块专注呈现角色在开局与日常状态下的真实面貌与关系可能；客观生理敏感度与底线集中放在 `sexual_information`，亲密互动表现独立成条。
- **聚焦常态规律与维度**：本体记录跨场景稳定的性格维度、处事原则、说话规律与关系定位；当前好感分值、即时衣着与单次场景状态交给聊天上下文与状态栏实时演化。

## 三个选择

| 选什么 | 判据 | 结果 |
|---|---|---|
| 档位 | 角色戏份 | `mini`（轻量配角）/ `standard`（常规主角，默认）/ `full`（多面深度角色）；作为骨架起步参考 |
| 路径 | 资料基础 | 有原作设定集、百科与文本 → 填充路径；原创概念或草稿 → 引导路径 |
| 模式 | 协作节奏 | 交互式（每关确认，默认）/ 直通式（信息齐备时连续推进；遇到信息缺口时同样停下向作者提问确认） |

- 三档共用同一套字段命名，低档精简可选分支，高档按实际素材展开。
- 精简顺序：优先合并无独有信息的泛化路径，其次压缩一般覆盖项，完整保留核心反差、独有机制与高辨识度规律。

## 衍生角色

按「原作基底人格 → 分支差分」顺序组织：先确立原作中稳定的认知方式与说话规律，再写分叉经历带来的泛化处境变化、新增目标与态度偏移；分叉点的单次具体往事拆入独立回忆绿灯。

## 泛化设定本体与条件绿灯语料节点（物理二元隔离架构）

动笔前先按当前角色向作者提交结构提案与角色卡预测输出方向：本体启用哪些泛化块、拆出哪几条条件绿灯（语料参考、过往事件、阶段模块、亲密表现），作者确认后再动笔：

| 物理载体 | 本质职责 | 包含内容 | 触发与写作要求 |
|---|---|---|---|
| **第一层：泛化设定本体（`<角色名>.md`）** | 决定角色是谁、靠什么逻辑感知与行事的全场景通用规律；换到任何新场景都直接成立 | `basic_settings`、`overview`、`personality`（九项判型、认知功能机制、`traits` 泛化言行倾向）、`appearance` & `sensory_details`、`clothing` 穿衣风格规律、`speaking_style`（`self_reference`、`addressing`、`speech_pattern` 句法节奏规律）、`relationships` 泛化定位与相处原则、`behavior_logic`、`decision_making_style`、`conflict_behavior`、`persona`（含 `past_shaping` 过往塑造因果）、`about_xxx` 专属机制边界、`sexual_information` 客观生理与技艺档位、`roleplay_tips` | 主角可常驻（开启双向防递归）或多角色按人名触发；写清底层心理因果与开放处事原则（用「平时…有时…一些情况下…在特殊情况下…」表达弹性），保持零具体台词原句、零固定微动作清单、零单次事件剧本 |
| **第二层：条件绿灯语料与事件节点（`<角色名>语料.md` / `过往事件.md` / `亲密表现.md`）** | 为特定交谈、回忆或亲密场景提供声纹气韵刻度与具体往事事实 | `<角色名>语料.md`（`dialogue_samples`、`punctuation_samples`、`habitual_movements` 微动作切片、`character_qa`、关系代表台词）；`<角色名>过往事件.md`（按时间排列的具体往事经过）；`<角色名>亲密表现.md`（`dlc_intimacy` 亲密反应与床笫台词样本） | 一律设 `constant: false` 按对应人物名、情境词、旧事词或亲密语境词按需触发；语料与亲密块顶行写明「仅供校准声线、语气与情绪刻度，正文中顺着现场态势生成全新言行」 |

- **底层驱动与开放可能性空间**：用角色自身的欲望、执念、职业习惯或关切目标驱动言行；人物的多面性按「什么情境与关系下自然显露哪一面」完整展开（例如松弛安全时全然温软、触及底线时全然冷硬），替代百分比成分配比或几分对几分的调色盘式写法，让每一面在对应情境下真实成立并保有自由生长的多种可能。当外在处境与内心想法交织时，依性格写出贴合本人的表里层次：守规坦率者直言底线，傲娇矜持者口是心非、半推半就，好强多疑者借故周旋，老练有城府者顺水推舟、设局试探。
- **条目独立自足**：每个节点直接陈述自身内容，依靠世界书关键词自然联动，省去跨条目指路说明。

## 各块职责

| 块 | 所在文件 | 承载内容与边界把握 |
|---|---|---|
| 类型学字段（`mbti` 至 `alignment`） | 泛化本体 | 纯粹的认知路径、评判标准、情绪阈值与心理防御机制分析 |
| `traits` / `hidden_traits` | 泛化本体 | 删掉特定对象与特定场景后依然成立的稳定性格倾向、说话态度与行事规律（配显现条件），原句台词与具体动作放入语料节点 |
| `speaking_style` | 泛化本体 | `self_reference`、`addressing`（各关系档位称呼切换规则）与 `speech_pattern`（句长、节奏、用词偏好、标点规律）；具体台词样本移入 `corpus` 节点 |
| `relationships` | 泛化本体 | 对关联人物的交集渊源、心理定位与惯常相处原则；具体对话原句移入 `corpus` 节点 |
| `behavior_logic` / `decision_making_style` / `conflict_behavior` | 泛化本体 | 日常处事、人际进退、取舍排序与冲突升级时的泛化原则与多方向弹性 |
| `emotional_expression` | 泛化本体 | 情绪外显的整体收放规律，以及在熟人与外人面前的分寸差异 |
| `persona`（偏好、短板、目标、`past_shaping`） | 泛化本体 | 喜好厌恶、认知盲区、长短期目标，以及过往经历留给当下性格的泛化因果锚点；具体单次往事拆入 `<角色名>过往事件.md` |
| `about_xxx` / `acquired` / `abilities` | 泛化本体 | 角色专属机制的成因、平时边界与转换条件；后天素质与现实能力的适用范围和限度 |
| `sexual_information` | 泛化本体 | 性经验背景、技艺熟练度档位、敏感带、情动生理信号、偏好分级与接受底线 |
| `roleplay_tips` | 泛化本体 | 卡尾 2～4 条简明扮演提示：锚定本我认知滤镜与核心驱动力、锁定称呼与知情边界、声明顺着现场态势自由生成全新言行 |
| `corpus`（`part="语料参考"`） | 独立条件绿灯 | 声线校准说明 + `dialogue_samples`、`punctuation_samples`、标志性微动作切片、`character_qa` 情境校准 |
| `dlc_intimacy`（`part="亲密表现"`） | 独立条件绿灯 | `usage_condition` + 声线校准说明 + 亲密节奏、互动反应开放采样、床笫纯台词样本与事后状态 |
| 独立阶段条目（`module`，`part="阶段X"`） | 独立条件绿灯 | 阶段概述、心理与相处距离变化、**当前阶段尺度与化解方式**；按最新阶段锚点与 `scan_depth: 1` 动态挂载 |

- **阶段演进与阶段事件的拆分**：
  - 角色本体只放初始常态泛化规律。随数值、关系或剧情跨阶段演进的内容，按阶段拆成独立 `module` 世界书条件绿灯，并在条尾写明正向的 **「当前阶段尺度与化解方式」**（交代本阶段亲密或信任上限停在哪里，对方超前试探时角色如何自然转移话题、礼貌挡回或借故拉开距离）。
  - 数值升降规则放入常驻 `rule` 条目；达成特定阈值触发的单次剧情节点（如摊牌、定情、决裂）放入条件 `event` 条目。
- **视角与知情真实**：角色通过观察 `{{user}}` 的言行举止做判断，保留猜错、误会与试探的真实感。

## 说话规律与独立语料节点

- **本体写规律，绿灯放原话**：泛化本体的 `speaking_style` 负责讲清自称切换、称呼规则、句子长短、停顿习惯与用词偏好；具体台词样本统一收进 `<角色名>语料.md` 条件绿灯，并在首行写明仅供校准声线气韵、正文中结合现场态势生成全新话语。
- **听得出是谁在说话**：语料节点精选能体现身份、脾气与呼吸节奏的纯口语台词，拿掉署名仍能一眼认出说话人。
- **口语戏称归语料，设定专名归设定**：角色在台词里的临时调侃、双关戏称或外号留在 `corpus` 节点作口语风味，保持设定本体专名干净。
- **贴合日常处境与知情范围**：日常语料围绕眼前生活与熟识对象展开，保持自然的知情边界。
- **自然语气词与多语种处理**：叹息、停顿与情动喘息使用自然的中文拟声与语气词（如「唔……」「哈啊……」「啧」）。外语原句作语感参照时，写明正文使用自然流畅的简体中文重现等价语气与节奏。

## R18 模块（按需启用：泛化生理留本体 + 具体表现拆绿灯）

需要 R18 内容时启用，按「日常净室边界 + 本体留泛化生理与态度 + 独立条件绿灯放具体表现与台词」组织，细则见 `references/nsfw.md`：

1. **物理二分清晰分工**：
   - 日常块只保留基础贴身衣物风格偏好（`clothing.underwear_and_details`）与亲密称呼规则（`addressing.intimate`）；
   - 泛化设定本体中的 `sexual_information` 只记录跨场景稳定的客观事实：经验背景与 **技艺熟练度档位**（如懵懂本能、青涩生疏、略通人事、熟稔老练、炉火纯青）、身体敏感带、情动生理信号（`arousal_signs`）、偏好标签分级与舒适底线；
   - 具体亲密动作、互动节奏与床笫纯台词样本拆为独立的 `<角色名>亲密表现.md` 条件绿灯（`type: module`，`<character name="…" part="亲密表现">`，配亲密语境触发词或 `secondary_keys`），首行写明启用条件与声线校准说明，日常与公开场合保持静默不注入。

## 引导路径（原创或概念角色）

1. **体验与预测输出方向对齐**：向作者提问确认核心体验方向、身份处境、关系起点与角色卡预测输出方向；信息未齐前先逐步提问补齐，待确认后再动笔。
2. **泛化内核构建**：确定 `core_stack`、认知功能运作方式、说话规律与处事原则，写入泛化设定本体。
3. **条件语料与往事展开**：与作者对齐声线调性后，单独编写条件绿灯语料节点与关键往事节点。
4. **汇总成稿**：将已确认的泛化本体与条件绿灯节点分别落盘入卡工程。

## 终检十问

1. 动笔前是否已向作者确认体验方向与角色卡预测输出方向，且所有关键信息缺口均已补齐而非靠脑补硬写？
2. 角色泛化设定本体（`<角色名>.md`）是否做到了全场景通用，彻底剥离了具体台词原句、单次微动作切片与单次事件剧本？
3. 独立语料节点（`<角色名>语料.md`）与亲密表现节点是否配置为条件绿灯（`constant: false`），并在首行写明了「仅供校准声线气韵、现场生成全新言行」？
4. 遮住名字单读 `corpus` 节点的台词样本，能立刻听出是这个人在说话吗？
5. 每个设定的主归属节点是否唯一清晰，日常块是否保持了干净的常态净室边界？
6. 穿搭、处事原则、冲突与亲密表现是否先立上位原则，再用「平时…有时…一些…例如…在特殊情况下…」留足了模型临场发挥弹性？
7. 人物面对压力或拉扯时，是否体现了贴合自身性格的多维表里层次？
8. 台词里的随口戏称是否留在了 `corpus` 口语层，日常语料是否贴合当下知情边界？
9. 全文是否做到了正面直接陈述，零双破折号、零生造四字词、零句内冗余解释括号、零虚空防御？
10. 角色用词、价值权衡与细节设定是否完全契合其所处时代、地域与身份阅历？
