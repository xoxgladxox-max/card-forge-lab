# 角色卡构建器（v3.5.0）

范围：角色本体、附加模块（module）和台词语料（corpus）怎么写、写到哪一关停。只建卡，不进入角色扮演。

| 在做什么 | 读 |
|---|---|
| 写 yaml、查字段、酒馆映射 | `references/template.md` |
| 选性格 / 外貌 / 性癖标签 | `references/era-traits.md` |
| 写 R18、写偷感 | `references/nsfw.md` |

总规则：

- 先核素材能不能进卡，再核属于哪个节点和字段，最后才看写法。上一层没过就停，不用下层修辞或模板填缺口。
- 每个原作事实要能追到料源或作者确认。旧卡只作线索，不作证据；无正向依据不写，不要求先证明原作没有。推断是提案，作者确认前不写成事实。
- 只改有材料证明的具体错误及其影响范围。一个外貌细节无据，不否定其他形态、其他事实或整个人格。重开已确认节点先征得作者同意并说明原因。
- 字段规则各管各的，一个字段的格式或禁令不迁移成全卡通则。
- 不设字数和条数上下限，以完全符合原作性格为准。写到能立住这个人就停，立不住就继续加。
- 表达精炼按 `cf-card-refine`：每条先立上位原则再收窄；性格、外貌、互动用现成概念和圈内通用 tag，不造词；作者沟通里的比喻只取机制，不写进人设；倾向写「当 X → 倾向 Y（限度 / 例外）」，不写固定流程。

## 输出格式

- yaml 包在 `<character name="人物名">` 里（标签表见卡的装配规则）。英文 key，中文 value。卡尾保留 `roleplay_tips` / `note` 扮演提示块。
- 「必须 / 始终 / 绝不 / 无论」只出现在 `roleplay_tips` / `note`、块内的使用条件字段（`dlc_intimacy.usage_condition`），以及独立阶段条目的 `行为界限（本阶段不会做的事）` 与阶段优先级声明。卡本体只写描述。
- `roleplay_tips` 写给扮演模型的指令，用祈使句，不写评论。
- 不写动态状态：当前好感度、当前场景、今天穿什么不进卡；卡写维度和倾向。

## 三个选择

| 选什么 | 判据 | 结果 |
|---|---|---|
| 档位 | 角色戏份 | mini ~1000 / standard ~5000（默认）/ full 不封顶；都是起步参考，不是上下限 |
| 路径 | 资料量 | 有原作 wiki、设定集 → 填充；模糊概念、原创 OC → 引导 |
| 模式 | 作者要不要参与 | 交互式（每关停，默认）/ 直通式（只停②⑥，各关报告并入⑥） |

- 拿不准选 standard。档位只定从哪副骨架起步。
- full 不封顶指字段数量，不是没有 token 预算。预算在 Phase 0 报数，贴着预算写；写满再砍会先砍掉具体细节、留下抽象概括。
- 三档字段路径完全一致，低档不另起字段名，不为子项另造英文二级标签。
- 降档顺序：先删无独有价值的低重要度路径，再压缩覆盖条目，最后才减普通语料。强调内容、独有信息、高辨识度细节不删。

## 衍生角色

分层写：原作基底人格 → 分支差分（分叉后变了什么、多了什么）。没变的引用基底，不复述。和世界观的「原作基底 → 分支差分」同理。

## 写到多细

模板是示例，不是填空题。动笔前按这个角色提结构提案：用哪些块、删哪些、新增哪些、各块写多深，作者确认后再写。

- 按 `上位概念 → 关键词 → tag → 具体细节` 逐层收窄（例：`互动风格 → 毒舌 → 抓住失误取笑 → 用反问指出错误`）。每层是作者的选择。
- 作者只想给范围时停在上位（`喜欢吃水果`）。说不清细节但有感觉时用参照锚点（`傲娇：像某作品某知名角色那样`），只取方向，不搬原角色的经历、口头禅和关系。写不出时只提问或列缺口。
- 细节写她注意什么、通常往哪反应、有哪些变化，不写固定顺序的动作。
- 每个设定至少改变语言、行为、选择、关系、场景或可追踪状态之一；没作用的删，同义词和上下位不重复占位。
- 兴趣、偏好、生活细节在资料允许时补对象、行为、时间或场合，给正文调用入口；不为凑丰富度编经历。
- 新概念先补它直接带来的作用、范围和限制；作者未确认的边缘问题列缺口，不扩写成体系。

信息密度（只处理已通过证据准入的内容）：

| 写法 | 条件 | 做法 |
|---|---|---|
| 强调 | 满足任一：作者想直接体验到；删掉后辨识度明显下降；别处推不出且补足独有信息 | 满足两项以上时提高密度，可在不同块出现三次左右，每处承担不同功能（例：`overview` 点出，`about_xxx` 讲透，语料落到言行）；次数随分量增减 |
| 覆盖 | 一般事实 | 只写在主归属块一次；覆盖事实、范围和关键方向，不穷举表现 |
| 留白 | 已知方向内的变化空间 | 保留开放：「对大多数事物提不起劲」不改成「始终提不起劲」；不写「遇到 X 必须做 Y」。留白不用于掩盖资料缺口 |

- 同一块里可以同时有强调、覆盖和留白，按内容条目判断，不按字段整块判断。
- 跨模块重复每处要换表达角度；只为填字段的重复是注水。非强调内容在主归属块之外再出现，也按注水处理。
- 不写跨条目引用：各块只写本块内容，不加指向其他条目或模块的引用说明。世界书按关键词注入，被引用的条目会自己出现；引用句不改变正文，只占 token。

缺东西时：翻原始素材 → 查站点 → 仍无支持就列缺口暂不写。前两步没走完，不把没做的功课变成作者的选择题。

格式与语言：

- 角色素材可用 Markdown / XML / 风味 YAML 组织层级；风味格式不等于可解析 YAML。需要导入的卡文件遵守目标格式。
- 源语言保留专有文化语境和口癖；英文标签可用于紧凑的客观特征；中文负责正文和示例台词。不把特定模型的语言偏好写成硬规则，不为省 token 牺牲可读性和语义。

## 各块写什么

| 块 | 写 | 不写 |
|---|---|---|
| 类型学字段（mbti 到 alignment） | 机制：认知路径、评判标准、情绪阈值、防御方式 | 剧情、道具、原句 |
| `traits` | 本性和方向，把 `core_stack` / `cognitive_functions` 落成具体的语言和行为方向；`解释` 只在有专属逻辑时写一句（好强：要证明自己是最优秀的造物） | 台词堆叠（原句进 `dialogue_samples`）；换说法复述术语 |
| `hidden_traits` | 与 traits 同形，多一项「何时露出」；确实存在、平时不外显的稳定性格面 | 性事中的主导欲（进 `dlc_intimacy`） |
| `behavioral_style` | 可观察的动作、姿态、节奏、距离、场合差异；常态动作写成一两个具体场景里的动作 | 分号清单；替 traits 定义性格；每个场景的固定动作 |
| `behavior_logic` | 日常、互动、压力下的稳定原则、注意力方向、变化范围 | 触发器到唯一反应的流程 |
| `decision_making_style` | 取舍原则、决策特征、少量高价值例子 | |
| `emotional_expression` | 情绪外显的幅度、可观察信号、变化余地 | 完整情绪查表 |
| `persona.preferences`、`character_weaknesses`、`daily_life`、`goals`、`key_facts` | 偏好习惯、已确认短板、生活事实、目标、客观经历 | 没有可靠内容的子块（直接删） |
| `abilities` / `conflict_behavior` | 身体条件与技能能做到什么、冲突场面的行动方向；服务辨识点（腿长就写腿能做到的事） | 战力数值、床上技巧 |
| `relationships` | 与具体人物、组织、群体的关系 | 性格描述；没有关键关系时的空条目 |
| `acquired` | 后天素质，与 relationships、traits、persona 同级；每条 `quality` + `source` + `threshold` + `effect` + `limits` | 凭空升阶；事件名冒充素质名 |
| `character_qa` | 按需用 `spoken` / `action` / `thought` 对照台词、反应和真实想法；`thought` 只在核心矛盾或隐性内容需要时用；`question` 只记客观时空与事件 | 每条硬造表里反差；作者对角色的解释 |
| `about_xxx`（角色专属机制块，确认后同级插入） | 角色独有的特殊机制（特殊体质、契约诅咒、独特心理运作回路）的前因、运作条件、行为方向与转换边界；用平实清楚的说明语言集中写透 | 自造口号式子键；原句台词堆叠（进 `dialogue_samples`）；与 `acquired` / `overview` / `key_facts` 重复抄写 |
| `roleplay_tips` / `note` | 写给扮演模型的 2–4 条元指令（称呼锁定、阶段防串台、禁读心）与红绿灯边界 | 外貌、衣着、经历时间线、关系事实、心理机制等任何角色设定素材的复述 |
| 独立阶段条目（`module`，按阶段拆世界书绿灯，**不放卡本体**） | 该阶段的 `阶段概述`、`心理与性格变化（内在变化 / 外在表现）`、`关系与核心行为`、`语言与台词参考`、`行为界限（本阶段不会做的事）` | 把多个阶段合在一条常驻发送；把一次性剧情事件混在阶段常态里 |

- 性格写性格，关系写关系。涉及特定对象的内容进 `relationships` 或关系专属块；性格条目不因出现对象名就删，先判断它是否仍在描述稳定性格。台词例外，但台词里的人必须在 `relationships` 里真实存在。
- **阶段变化、阶段语料与阶段事件全部拆为独立世界书条目，严禁塞进角色卡本体**：
  - 角色卡本体（`character`）只写角色在开局或常态下的基准面貌。
  - 凡涉及随数值、关系或剧情递进的多阶段转变（如受挫恢复、防备破冰、黑化、态度软化、价值观重塑），每个阶段单独建一条 `module` 世界书条件绿灯（见 `references/template.md`「角色阶段条目怎么写」），仅在命中当前阶段锚点时激活，并声明「当前阶段特征与语气优先于基础人设」。每阶段必写 `行为界限（本阶段不会做的事）` 锁死升级节奏。
  - 若特定阶段（如情绪崩溃、彻底卸下伪装）完全不再使用日常口头禅，将日常语料拆为独立 `corpus` 条目并用二级过滤排除该阶段，改由该阶段条目内的专属台词接管。
  - 数值升降规则与阶段区间对照表单独建常驻 `rule` 条目；达到某阶段阈值触发的特殊剧情（如表白、决裂、摊牌）单独建条件 `event` 条目，不塞进角色卡本体或阶段常态条目。
- 角色不读心：只能从 user 说了什么、做了什么去猜，可以猜错。
- 冲动是可能性不是剧本：极端行为写明触发条件（例：情绪激动时），放独立 module 并带使用条件，不进 `traits` 和 overview；用中性状态词，不用把事情往绝路上推的词。

## 语料

- 台词最要紧，数量不设限（参考：mini 8 / standard 20 / full 30+）。拿掉署名还认得出是谁；认不出就继续补。台词从素材精选，不编造。
- 保留角色专属的原生台词、口癖、拖音与♡符号作语感锚点；原作名号、代号、道具名不泛化替换。
- 输出规范里必须同时写明：外语素材是语感参照，不是翻译源文本，正文用简体中文重新创造等价的语气和节奏。只写前半句，正文会带回外语残留。
- 冷门题材的关键道具、事件、台词年表、术语单独成块收进卡，写到不查外部资料也能用；大众题材报名字即可。
- 「倾向」「会」这类描述注意力去向的词是合规写法；要禁的是说明文腔和主观感受词。

## R18 模块

只在要 R18 时写，取样与检查见 `references/nsfw.md`。

- 三块解耦：`角色卡本体`（日常）+ `sexual_information`（事实：经验、敏感带、情动生理信号、性癖标签与好恶）+ `dlc_intimacy`（动作块：每块一个能演的动作，块里给台词）。
- 本体只留三类与性沾边的内容：衣着事实（`clothing.underwear`）、称呼索引（`addressing.intimate` 一行）、`hidden_traits` 里不带性场景的稳定性格面。其余散在各块的性内容（外貌块的情动反应、`behavioral_style` 的亲密姿势、`emotional_expression` 的情动表、`abilities` 的床上技巧、关系块的性事台词）全部搬进两块，本体不留副本。
- `dlc_intimacy` 开头写 `usage_condition`：什么情况下才读这一块（{{user}} 主动，或关系自然走到那一步），其余时候完全静默；{{user}} 一退，这块跟着退。
- `behavior` 用客观的英文写底层行为逻辑；`anchoring_dialogue` 直接用日系原生标签与词汇，不用机翻。
- 不分阶段表单（「初中后段 / 三阶段」这类），写成动态情境与切换。日常特质延伸进亲密场景；同一声线里升格与降格交替；事后用言语重新定义快感来源。
- 床上和平时是同一套口调、句式、称呼，变的只有内容；她独有的东西进 `dlc_intimacy`。
- 一个模块里并列几种玩法时，按 `nsfw.md` 第七节写：framework 写不变量和条件镜头；每个玩法写 trigger、tendency、exit；玩法之间不共用台词；必写 breaking_condition。

## 填充路径

先一步写满，再逐轮审查。每关停下等作者。

| Phase | 做什么 | 关口 |
|---|---|---|
| 0 搜集 | 至少两个来源交叉 → 提取台词、行为证据、外貌、关系 → 归档 → core_stack 初判 → 列缺口 → 定档位、模式、预算 | 停①：归档清单、初判、缺口、预算 |
| 1 出货 | 按 `template.md` 逐段填；traits 标签参考 `era-traits.md`，回头对比行为证据 | 停②：完整初版 + 自己拿不准的 3–5 点 |
| 1.5 回核 | 拿初版回站上七对：外貌、经历、关系、台词原文、core_stack 九项、别号口癖、缺口。每项标 ✅命中 / ⚠️受阻（写原因）/ ❌确认无记载 | 停②½：七对表、冲突项、建议改动 |
| 2a 查性格 | 标签是性格词吗？删人名还成立吗？traits 是落成了具体方向，还是换说法复述术语？类型学字段有没有剧情和原句？各行为块职责混淆没？`acquired` 用的是素质名还是事件名？ | 停③：修订报告 |
| 2b 查原作 | 停②½ 的改动落实了吗？九项哪些有依据、哪些自推，标清了吗？有没有拿单篇评论推翻整体判断？ | 停③½：修订报告 |
| 2c 查台词 | 拿掉署名认得出吗？AI 味七项？自称和称呼跨场景一致吗？ | 停④：修订报告 |
| 3 查关系 | 关系条目混进性格描述没？有没有读心？`acquired` 每条有依据和边界吗？是否误写成关系专属或先天性格？ | 停⑤：修订报告 |
| 4 NSFW（要 R18 才跑） | 读 `nsfw.md`。散落的性内容集中：事实进 `sexual_information`，动作与台词进 `dlc_intimacy` → pixiv 按标签取样读正文 → 按动作拆块 → 对齐平时口调 → 写 `usage_condition` | 停⑤½：搬运清单、取样清单、新写的块 |
| 5 收尾 | 合并修正，跑十问终检，套 XML | 停⑥：终检、token 数、最终卡 |

性格靠行为证据推，原作靠站点考据，台词靠耳朵，所以三查分三关。mini 档只停②⑥，1.5 只核外貌和 core_stack，三查合并一轮。

关口规则：

- 报告格式：本轮查项 / 问题 N 处 / before → after / 存疑待定。只列 diff，不重贴全卡。三查是内审，作者行使否决权，不是重读全卡。
- 停②拦方向性错误，不等三查跑完才推翻；要主动暴露拿不准的点。
- 停②½ 只报核对结果，不夹带自己想改的；作者拍板前 yaml 一个字不动。
- 修改按最小范围：只改有材料证明的错误及受影响内容。保护已确认内容不等于保留所有旧稿，旧稿也不因一处疑点全盘作废。
- 三查以信息密度为准：可删机械重复、合并低价值路径，不删强调内容、独有信息、辨识点，更不得擅自删除已确认的顶层/中层模块（如自建的 `about_xxx` 角色专属机制模块）；遇到跨块重复时，按各块唯一主归属清理越界复述。发现缺内容记进「收尾补录清单」留到 Phase 5。可以把覆盖改完整、把留白改开放，不凭空加设定。

## 引导路径

不编，边问边补，每步等确认。

1. 基础锚定：身份处境 + 一句话概括（不用性格词）+ 背景客观事实。不够就分点提问，不出模板。
2. 性格展开：先定 `core_stack` 与 `cognitive_functions`，再逐层收窄写 `traits`；作者只给了感觉时停在参照锚点。确实有不宜外显的稳定内容时才写 `hidden_traits`。
