# era 标签库

来源：eratoho / EraUma / eraAWT 的角色素质系统。选性格、外貌、性癖标签时对着挑。
起名法：**短、准、一看就知道这人大概什么样**。不造新术语——写「她怕痛」不写「疼痛感知敏感度高」。

## 附：性格卡壳时的追问清单

口调 / 悪癖 / 思考 / 目线 / 忍耐 / 对自己坦率 / 对他人坦率 / 对自己关心 / 对他人关心 / 独占 / 情绪。

各写一句，性格就立起来了，而且每项都是可观测的行为倾向。示范（eraAWT「阴沉粘人」作者笔记）：

- 口调：语尾多用「……」和「……❤」，口癖是「○○なんて……」
- 悪癖：不太考虑别人，以自我为中心
- 思考：想成为对方的第一，但同时要占上风
- 目线：因为想占上风，所以是俯视
- 忍耐：不算能忍，为了当第一能强忍，但也会爆发
- 对自己坦率：超级坦率；对他人坦率：还算坦率，情绪外放，但不太配合别人
- 对自己关心：不高，当上第一才涨一点；对他人关心：只对特定对象极度关心（「那天你和别人做什么了？」）
- 独占：独占欲的集合体，但本人几乎没有自觉
- 情绪：经常行踪不明，自己都抓不准

作者的自我定位：「不是模板 ヤンデレ，是抽掉了精神疾病成分的黏人。喋り口调是腹黑和傲娇按 4.5:5.5 混出来的。」——同一个大方向也有强弱变体，加个修饰词就拉开差距。
