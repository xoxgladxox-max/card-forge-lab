# era 标签参考库

来源：eratoho / EraUma / eraAWT 角色素质体系。挑选性格、外貌、体质与偏好标签时用作速查菜单。
选词原则：**短、准、一眼见人**。优先使用直观现成词，例如直接写「怕痛」而非生造「疼痛感知敏感度高」。

## 二、心理与感情状态（供 `hidden_traits`、`emotional_expression`、阶段模块选词）

**情感防线**：自制心／淡漠旁观／好奇试探／谨守礼防／一诺千金／渴求关注

**羞耻与界限**：重诺守贞／随性洒脱／压抑克制／坦然释放／害羞易红／落落大方／排斥异己

**深层关系状态**：

| 标签 | 状态表现 |
|---|---|
| 恋慕 | 心意牵挂对方，言行间自然偏袒与靠近 |
| 笃信 | 将对方的话奉为圭臬，判断标准向对方倾斜 |
| 亲爱 | 深厚信赖与松弛感并存，卸下日常防备 |
| 顺服 | 认可对方的主导地位，愿意听从安排 |
| 铭刻 | 身心习惯了对方的气息与痕迹，难以割舍 |
| 依附 | 将自身安全感与归属完全系于对方身上 |

## 五、亲密偏好与接受度（供 `sexual_information` 选用）

### 互动倾向

| 标签 | 行为质感 |
|---|---|
| 坦率迎合 | 对欢愉反应诚实，舒服便自然贴近哼出声 |
| 嘴硬否认 | 身体已有反应仍咬唇硬撑，事后找理由遮掩 |
| 易食髓知味 | 一旦尝过亲近滋味便暗自惦记、主动制造独处机会 |
| 慢热深情 | 依赖情感铺垫与安全感，心定之后格外投入 |
| 施虐主导 / 受虐依从 | 偏好掌控节奏逗弄对方，或偏好交出主导权受人摆布 |
| 小恶魔逗弄 | 热衷撩拨试探看对方失态，点到即止吊人胃口 |
| 矜持保守 / 大胆主动 | 面对亲密提议时的起手态度差异 |

**技艺与擅长方向**：唇舌伺候／胸乳温存／纤手抚慰／足尖撩拨／主动骑乘／依偎缠绵

### 接受度分级写法

挑选 3～5 项最贴合角色性格的偏好，标明具体接受度（**喜爱／愿意配合／视气氛尝试／抗拒／严守底线**），比笼统贴一个大标签清晰得多。

## 六、自称与称呼切换

- **女性常用自称**：我 / 人家 / 本小姐 / 本宫 / 妾身 / 贫道 / 小女子 / 姐姐我
- **男性常用自称**：我 / 在下 / 鄙人 / 本座 / 老夫 / 小爷 / 吾 / 朕

角色在不同场合或面对不同亲疏对象切换自称时，一并写清各称呼对应的启用语境（例如公事场合自称职务或「本座」，私下独处软化为「我」）。

## 附：人物性格卡壳时的十一问速写

口调、小毛病、盘算重心、视线高低、忍耐力、对自己坦率度、对旁人坦率度、自我爱惜度、对意中人关注度、占有欲、情绪起伏。

每项用一句大白话写出可观察的行为，人物骨架立刻清晰。示例（粘人好胜型角色速写）：

- 口调：句尾常拖半拍「……」或带轻巧鼻音，爱用反问句试探对方底细
- 小毛病：凡事习惯先按自己的喜好排先后，旁人插嘴时容易微蹙眉头
- 盘算重心：既想成为对方心里独一份的首位，又要在相处体面上占住上风
- 视线高低：为了撑住上风姿态，说话时常微抬下巴端详对方神色
- 忍耐力：为争第一能把委屈咽回肚里强撑许久，私下独处时才冷脸生闷气
- 坦率与占有：对自己想要什么心里门儿清，见对方与旁人说笑便会不动声色走过去插话截胡
