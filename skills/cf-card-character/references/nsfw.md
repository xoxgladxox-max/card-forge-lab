# R18 亲密模块与特定流派选读

需要编写 R18 内容（本体 `sexual_information` 与独立条件绿灯 `dlc_intimacy`）时参考本文件。动笔前先执行「两原则一问题」：写出明确判断与角色卡预测输出方向，排查死板套路；若缺乏关键偏好、尺度或体验方向信息，立即停下向作者提问补齐后再成文。

前半部分为全角色通用的「泛化生理留本体 + 具体表现拆条件绿灯」写法；后半部分为两个可选流派示例（言语主导与隐秘同场），仅在角色属性确实契合时选用。

---

## 一、通用写法：泛化生理事实留本体 + 具体互动表现拆条件绿灯

### 1. 三层物理隔离

- **日常卡本体保持常态净室边界**：日常块专注呈现人物常态下的身份、志趣、事业与关系张力。贴身衣物仅在 `clothing.underwear_and_details` 客观记录日常款式偏好，在 `speaking_style.addressing.intimate` 留一行亲密称呼切换规则。
- **`sexual_information` 留在角色泛化本体（只记跨场景客观事实与原则）**：
  - `experience_and_skill`：写明过往经验背景与客观的**技艺熟练度档位**（如懵懂本能、青涩生疏、略通人事、熟稔老练、炉火纯青），让模型把握角色的熟练基准；
  - `body` 与 `arousal_signs`：写明敏感带、体质特点，以及情动时的生理变化规律（耳根升温、眼神湿润或游移、呼吸变浅、嗓音微哑等）；
  - `kink_tags` 与 `attitude_and_boundaries`：按接受度分级列出偏好标签、对待亲密关系的整体态度原则与舒适底线。
- **`dlc_intimacy` 拆为独立的 `<角色名>亲密表现.md` 条件绿灯（`type: module`，`constant: false`）**：
  - 节点顶层包裹 `<character name="角色名" part="亲密表现">`，通过角色名配合亲密氛围二级过滤词按需触发，日常交谈与公开场合静默不注入。
  - 首行 `usage_condition` 写明启用情境（双方独处且情感与肢体接触自然进入亲密阶段时启用，对方收手或退开时随之平复），第二行 `calibration_notice` 写明「以下动作与台词样本用于标定角色在亲密情境下的声线温度与反应光谱，正文中随现场信任度与互动节奏自然生成全新表现」。
  - 内部使用平实清晰的子键（`tone_and_pacing`、`service_and_reactions`、`preferences_in_action`、`boundary_handling`、`language_samples`、`climax_and_aftercare`），先定上位原则，再用 **「平时/通常……」「有时……」「一些情况下……还有一些情况下……例如……」「在特殊情况下……」** 给出开放反应光谱。

### 2. 声线一贯与多层次言行反应

- **床上与平时是同一个人**：亲密场景延续泛化本体 `speech_pattern` 里的句长、自称、称呼规则与说话习惯。平时说话简短克制的人，动情时话更碎更轻；平时习惯反问或拿腔拿调的人，情动时也会顺着原口吻嘴硬或试探。
- **同档位角色的本我差异化生长**：两个角色即便同属一个技艺熟练度档位（如【略通人事】），也从各自的本我内核（`MBTI` 认知功能、执念来源与身体特质）生长出截然不同的互动倾向：例如重礼守诺的古典性格围绕隆重礼数、半遮面羞怯配合展开；冷静多疑的谋划型性格围绕贴近胸口确认心跳与安全感、言语心理试探与暗借随身器物控局展开。把角色自身的器物、职业习惯与体质特征自然融入互动。
- **高潮与事后反应贴合性格**：根据人物底色写出真实的表里层次。坦率热烈者自然流露依恋；清冷自持者事后沉默整理衣襟、耳根留红；傲娇好强者一边轻喘一边偏头找借口掩饰；老练主动者反过来端详或调侃对方。生理情动与人物独立意志并行留存。
- **自然中文语气词**：喘息、轻哼与停顿使用自然流畅的中文语气词（如「唔……」「嗯……」「哈啊……」「慢一点……」）。

## 二、流派选读 A：言语主导与节奏掌控（适用于主动拿捏型角色）

当角色明确具备言语主导、逗弄拿捏倾向时，可通过高收藏同类型短篇小说观察实操句感，提炼说话节奏规律。

### 1. Pixiv 文本取样方法

使用本机已登录的持久浏览器配置访问搜索接口获取高收藏样本：

```text
https://www.pixiv.net/ajax/search/novels/<关键词>?word=<关键词>&order=date_d&mode=r18&p=1&s_mode=s_tag&lang=ja
```

- `s_mode=s_tag` 为标签部分匹配（多标签以 `%20` 连接），`s_tag_full` 为精确匹配；从 `body.novel.data` 读取 `id`、`bookmarkCount`、`textCount`、`tags`。
- 优先挑选收藏数高、两千字左右的精炼短篇，从 `https://www.pixiv.net/novel/show.php?id=<id>` 读取正文，重点观察四件事：
  1. **断句位置**：一句多长，在哪里停顿留白；
  2. **沉默的用法**：停下来等对方开口时，把对方的沉默当成什么信号；
  3. **夸奖与敲打的组合**：先顺毛安抚再轻刺一句，还是用哄劝的口气提出要求；
  4. **发令句式**：用疑问句、商量句还是轻描淡写的陈述句引导对方主动开口。

### 2. 多模式并列结构（放入独立的 `<角色名>亲密表现.md` 条件绿灯）

当角色在亲密场景中有几种不同拿捏玩法并列时，可在独立亲密绿灯节点内用 `framework + modes` 组织：

```xml
<character name="角色名" part="亲密表现">
dlc_intimacy:
  usage_condition: 两人独处且进入亲密互动时启用；有旁人在场或互动结束后静默。
  calibration_notice: 以下各模式的台词与动作均为声线节奏采样，实际扮演时结合现场互动生成全新表达。
  framework:
    不变量: 语气始终轻快平缓，多用短句与尾音上扬的疑问句，尺度加深时语速依然从容。
    关注焦点:
      - 掌控节奏时留意对方的呼吸变化、指尖松紧与眼神游移
      - 对方急切越界时停手观察对方的反应，再决定安抚或微调距离
  modes:
    逗弄引导:
      trigger: 对方显得急切或目光直白时
      tendency: 用温和夸奖的口吻点破对方的局促，有时放慢动作等对方先开口说明心意
      exit: 对方真正流露窘迫或沉默偏头时，自然收敛逗弄转为寻常温存
      dialogue_samples:
        - "嗯，这么心急呀……先把话说明白，想要我怎么做？"
    节奏设限:
      trigger: 对方未经示意直接伸手索取时
      tendency: 轻轻按住对方的手背停顿片刻，待对方顺从放缓后再给予安抚奖励
      exit: 对方跟上节奏后转回正常亲昵互动
      dialogue_samples:
        - "等一下，先把呼吸放平……乖，再等一会儿。"
  rhythm_shift: 当对方坦然定神回望或温和反客为主时，她原本游刃有余的步调会出现短暂慌乱，流露出少见的局促与羞意。
</character>
```

## 三、流派选读 B：隐秘同场张力（适用于含旁人在场暗中互动的角色）

当角色互动包含「明面维持日常社交、暗处两人心照不宣私下接触」的设定时选用。

### 1. 明暗两层同场并行

隐秘互动的张力来自明面日常秩序与暗处私密接触在同一时空并存：明面上的交谈、议事、用餐或授课越如常，桌下或衣袖掩映处的细微触碰就越鲜明。

### 2. 三重心理支点与克制感官

1. **警觉与贪恋并存**：既留意旁人视线维护体面，又恋恋不舍地维持细微接触。
2. **共享秘密的默契**：在一众不知情者面前共享只有彼此读得懂的眼神、双关话语或微动作。
3. **收敛下的感官细节**：聚焦放轻的呼吸、衣料轻擦、一触即分的视线，以及为了维持端坐或站稳而暗自收紧的力道；旁人视线靠近时短暂屏息收敛，视线移开后或顺势收手，或试探半寸。

### 3. 落入泛化本体与亲密绿灯的对应位置

- 泛化本体 `behavior_logic`：写明公开场合与私下独处的分寸差，以及暗中试探时由浅入深的进退原则；
- 泛化本体 `emotional_expression`：写明维持镇定时情绪收放的规律差异；
- 独立绿灯 `dlc_intimacy`：延续日常声线，注明在需压低动静的情境下以眼神、口型与极轻的气音交流，并提供气韵采样。
