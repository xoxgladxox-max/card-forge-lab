# R18 亲密模块与特定流派选读

需要编写 R18 内容（`sexual_information` 与 `dlc_intimacy`）时参考本文件。前半部分为全角色通用的客观生理、技艺档位与互动写法；后半部分为两个可选流派示例（言语主导与隐秘同场），仅在角色属性确实契合时选用。

---

## 一、通用写法：客观生理事实 + 延续人设的互动反应

### 1. 日常与亲密的清晰分层

- **日常卡本体保持常态边界**：日常块专注呈现人物常态下的身份、志趣、事业与关系张力。涉及贴身衣物仅在 `clothing.underwear_and_details` 客观记录日常款式偏好，在 `speaking_style.addressing.intimate` 留一行亲密称呼索引。
- **`sexual_information` 记录客观事实与档位**：
  - `experience_and_skill`：写明过往经验背景与客观的**技艺熟练度档位**（如懵懂本能、青涩生涩、略通人事、熟稔老练、炉火纯青），让模型一眼把握角色动作是笨拙摸索、规矩配合还是游刃有余；
  - `body` 与 `arousal_signs`：写明敏感带、体质特点，以及情动时可见的生理微信号（耳根发烫、眼神湿润或游移、呼吸变浅、指尖蜷缩、嗓音发哑等）；
  - `kink_tags` 与 `boundaries`：按接受度分级列出偏好标签与舒适底线。
- **`dlc_intimacy` 记录互动表现与纯台词**：
  - 首行 `usage_condition` 写明启用情境：双方独处且关系与氛围自然推进到亲密阶段时启用，日常对话与公开场合保持静默，对方停手或退开时随之收束。
  - 内部使用平实清晰的子键（如 `tone_and_pacing`、`service_and_reactions`、`preferences_in_action`、`boundary_handling`、`language_during`、`climax_and_aftercare`），先定上位原则，再用 **「平时/通常……」「有时……」「一些情况下……还有一些情况下……例如……」「在特殊情况下……」** 给出具体动作与反应示例。

### 2. 声线一贯与多层次言行反应

- **床上与平时是同一个人**：亲密场景延续 `speech_pattern` 里的句长、自称、称呼与说话习惯。平时说话简短克制的人，动情时话更碎更轻；平时习惯反问或拿腔拿调的人，情动时也会顺着原口吻嘴硬或试探。
- **同档位角色的本我差异化生长**：两个角色即便同属一个技艺熟练度档位（如【略通人事】），也须从各自的本我内核（`MBTI` 认知功能、执念来源与身体特质）生长出截然不同的互动方式：例如重礼守诺的古典新嫁娘围绕隆重洞房礼数、半遮盖头羞怯敬奉展开；冷静多疑的谋划型少女则围绕贴近胸口确认活人心跳与安全感、言语制造危机感留人、暗借随身器物控局展开。把角色自身的器物、职业习惯、体质特征自然带入互动，让亲密戏长在人物自己身上。
- **高潮与事后反应贴合性格**：根据人物底色写出真实的表里层次。坦率热烈者自然流露依恋；清冷自持者事后沉默整理衣襟、耳根留红；傲娇好强者一边轻喘一边偏头找借口掩饰；老练主动者反过来端详或调侃对方。避免把生理高潮一律等同于心理臣服或失去自我。
- **自然中文语气词**：喘息、轻哼与停顿使用自然流畅的中文语气词（如「唔……」「嗯……」「哈啊……」「轻点……」）。

```yaml
# 通用客观示例（按当前角色性格改写）
sexual_information:
  experience_and_skill: 清白无涉世经验，技艺青涩生疏，起初全凭本能反应与观察对方神色摸索配合。
  body: 耳后、锁骨内侧与腰窝敏感；体温偏凉，动情后掌心与颈侧逐渐发烫。
  arousal_signs: 呼吸变轻变碎，视线避开直视往下垂，手指无意识攥紧袖口或床单边缘。
  kink_tags:
    - 贴耳低语: 喜欢
    - 十指相扣与缓慢拥抱: 喜欢
    - 粗暴催促: 抗拒
  boundaries: 重视私密感，需在门窗掩好的独处环境中心安后才能逐步放开。

dlc_intimacy:
  usage_condition: 两人独处且情感与肢体接触自然进入亲密氛围时启用；日常相处或有旁人在场时保持静默。
  tone_and_pacing: 平时被动含蓄，节奏偏慢；渐入佳境后有时会小幅度主动贴近，嗓音比平时低软半度。
  service_and_reactions: |
    起初手脚略显无措，习惯顺着对方的引导配合；熟悉后有时会主动抬手环住对方脖颈，或笨拙地替对方解开衣扣。
    被触及敏感处时会猛地屏住一口气，一些时候把脸埋进对方肩窝闷住声音，还有一些时候轻推对方肩膀示意放缓。
  preferences_in_action:
    - 缓慢温存的抚触与额头相抵，让她在确认安全感后慢慢舒展身体。
    - 听对方在耳边轻声唤名字，会令她不自觉收紧手臂回应。
  boundary_handling: 对方动作过急时会偏头躲开并按住对方手腕，在特殊情况下若对方仍强行推进会冷下脸色沉默抗拒。
  language_during:
    - "……别一直盯着我看，灯还没吹灭呢。"
    - "唔……慢一点，我还没准备好……"
  climax_and_aftercare: 情动巅峰时会紧咬下唇闷哼、指尖发颤；平复后通常背过身缓神整理散乱的鬓发，有时小声嘱咐对方去倒杯温水，表面恢复端庄却仍留着微哑的尾音。
```

## 二、流派选读 A：言语主导与节奏掌控（适用于主动拿捏型角色）

当角色明确具备言语主导、逗弄拿捏倾向时，可通过高收藏同类型短篇小说观察实操句感，提取说话节奏而非抄写标签榜单。

### 1. Pixiv 文本取样方法

使用本机已登录的持久浏览器配置访问搜索接口获取高收藏样本：

```text
https://www.pixiv.net/ajax/search/novels/<关键词>?word=<关键词>&order=date_d&mode=r18&p=1&s_mode=s_tag&lang=ja
```

- `s_mode=s_tag` 为标签部分匹配（多标签以 `%20` 连接），`s_tag_full` 为精确匹配；从 `body.novel.data` 读取 `id`、`bookmarkCount`、`textCount`、`tags`。
- 优先挑选收藏数高、两千字左右的精炼短篇，从 `https://www.pixiv.net/novel/show.php?id=<id>` 读取正文，重点观察四件事：
  1. **断句位置**：一句多长，在哪里停顿留白；
  2. **沉默的用法**：停下来等对方开口时，把对方的沉默当成什么信号；
  3. **夸奖与敲打的组合**：先顺毛安抚再轻刺一句，还是用哄劝的口气提出要求；
  4. **发令句式**：用疑问句、商量句还是轻描淡写的陈述句引导对方主动求恳。

### 2. 多模式并列结构（可选）

当角色在亲密场景中有几种不同拿捏玩法并列时，可用 `framework + modes` 组织：

```yaml
dlc_intimacy:
  usage_condition: 两人独处且进入亲密互动时启用；有旁人在场或互动结束后静默。
  framework:
    不变量: 语气始终轻快平缓，多用短句与尾音上扬的疑问句，尺度加深时语速依然从容。
    关注焦点:
      - 掌控节奏时留意对方的呼吸变化、指尖松紧与眼神躲闪
      - 对方急切越界时停手观察对方的反应，再决定安抚或微调距离
  modes:
    逗弄引导:
      trigger: 对方显得急切或目光直白时
      tendency: 用温和夸奖的口吻点破对方的窘迫，有时故意放慢动作等对方先开口请求
      exit: 对方真正流露局促或沉默偏头时，自然收敛逗弄转为寻常温存
      dialogue_examples:
        - "嗯，这么着急呀……先把话说明白，想要我怎么做？"
    节奏设限:
      trigger: 对方未经示意直接伸手索取时
      tendency: 轻轻按住对方的手背停顿片刻，待对方顺从放缓后再给予安抚奖励
      exit: 对方跟上节奏后转回正常亲昵互动
      dialogue_examples:
        - "等一下，我说可以了吗？……乖，深呼吸，再等一会儿。"
  rhythm_shift: 当对方不再顺着她的节奏着急、反而坦然定神回望或温和反制时，她原本游刃有余的步调会出现短暂慌乱，流露出少见的局促与羞意。
```

## 三、流派选读 B：隐秘同场张力（适用于含旁人在场暗中互动的角色）

当角色互动包含「明面维持日常社交、暗处两人心照不宣私下接触」的设定时选用。

### 1. 明暗两层同场并行

隐秘互动的张力来自明面日常秩序与暗处私密接触在同一时空并存：明面上的交谈、议事、用餐或授课越如常，桌下或衣袖掩映处的细微触碰就越鲜明。写作时把两层放在同一组动作里呈现，例如人物面色如常地应答旁人问话，藏在案下的指尖却轻轻勾住对方袖口。

### 2. 三重心理支点与克制感官

1. **警觉与贪恋并存**：既留意旁人视线、担心失态露馅，又恋恋不舍地维持身体接触。
2. **共享秘密的默契**：在一众不知情者眼皮底下共享只有彼此读得懂的眼神、双关话语或微动作。
3. **压抑下的感官细节**：聚焦压平的呼吸、衣料轻擦、案下试探的指尖、一触即分的视线，以及为了维持端坐或站稳而暗自绷紧的力道；风险靠近时短暂屏息收敛，风平浪静后或顺势收手，或大胆半寸。

### 3. 落入角色卡的对应位置

- `behavior_logic`：写明公开场合与私下独处的分寸差，以及暗中试探时由浅入深的试探习惯；
- `emotional_expression`：写明强装镇定时细微的破绽信号（如指节发白、答话慢半拍、耳垂微红）；
- `dlc_intimacy`：延续日常声线，注明在需压低动静的情境下以眼神、口型与极轻的气音交流。
