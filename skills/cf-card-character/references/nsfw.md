# R18 怎么写

只在用户要 R18 时读。前面几关的写法这一关全部不适用——性格靠行为证据推、原作靠站点考据，这块两样都靠不上，得先去读真人写的、有人看的东西，看他们怎么下笔，再回来写卡。

---

## 一、先去读正文，别去看榜

**不许拿销量榜、标签排行、商品分类当依据。** 那是给买家挑货用的分类，不是写的人怎么写。把「射精管理 第5位」抄进卡里，卡上得到的是一个词，不是一句能用的话。

**也不要读写法讲座。** 讲座讲的是作者的一般观念，而且往往过时。2014 年的男性向讲座会告诉你「把女角色写得越像物体越好」——碰上一个女性主导的角色，整套建议全部反过来。

要读的是**正文**。找收藏数高的、标签对得上的，把正文拉下来看句子。

## 二、上 pixiv 取样

R18 小说要登录才看得到正文。用本机 Chrome 持久 profile 有头开一次让用户登录，关窗口，之后全走 headless 同 profile。

搜索走 ajax 接口，返回 JSON，直接拿得到收藏数：

```
https://www.pixiv.net/ajax/search/novels/<关键词>?word=<关键词>&order=date_d&mode=r18&p=1&s_mode=s_tag&lang=ja
```

- `s_mode=s_tag` 标签部分匹配，多标签用空格（URL 编码成 %20，不是 +）；`s_tag_full` 完全匹配，命中少但准
- 返回 `body.novel.data` 里有 `id` / `bookmarkCount` / `textCount` / `title` / `tags`
- 接口只按时间排序，收藏数自己排

正文页 `https://www.pixiv.net/novel/show.php?id=<id>`，剥标签取文本。出现「无法浏览R-18作品」就是没登录成功。

挑哪些读：按收藏数排取前几篇；标签要对得上角色（女性主导就搜 女性上位／女性優位，说话温柔内容残酷就搜 甘サド／優しい言葉責め）；**收藏数极高的短篇优先**——几千收藏的两千字作品，靠的是句子本身，不是篇幅和剧情。

## 三、从正文里只看这四样

1. **她的话怎么断的。** 一句多长，在哪停，停几次。
2. **什么时候不说话。** 沉默被当成什么处理——同意？答案？
3. **夸和贬怎么放在一起。** 先夸后贬，还是同一句里混着。
4. **命令用什么句式发出来。** 命令形？邀请形？疑问形？

实际取样的结果（`優しい言葉責め`，8974 收藏，1910 字）：那篇**整篇没有一句地文**，全是台词加拟声词。这条比任何讲座都有用——读者要的是她说的话，不是「她温柔地说」。

## 四、写进卡的哪里

不要开一个大字段把东西全塞进去。**按动作拆块**，每块是一个能演的动作，块里直接给台词。

事实类内容——经验、敏感带、情动时看得见的生理反应、性癖标签与好恶——不放这里，放 `sexual_information`（形状见 template.md 第 10 块）。这里只放动作与话。

动手之前先做一次搬运：把卡本体各块里散落的性内容（外貌块的情动反应、行为块的亲密姿势、情绪表的 aroused、能力块的床上技巧、关系块的性事台词）全部收进这两块，本体不留副本。

```yaml
dlc_intimacy:
  usage_condition:           # 什么场景读、其余时候完全静默，必写
  Dominance_Submission:      # 位置 + 风格 + dynamic_balance（必写切换条件）
  before_touching:           # 开始之前她做什么
  telling_him_what_he_does:  # 她怎么描述对方
  praise_and_belittle:       # 夸和贬
  refusing:                  # 拒绝的时候
  kinks:                     # 每条是可执行动作，不是名词
  language_during:           # 行为中的话
  own_orgasm:                # 她自己失控的样子
  post_scene:                # 结束之后
  breaking_condition:        # 什么情况下她的手段全部失效
```

块名跟着角色走，上面只是个形状。角色不是主导方就换别的块。

**kinks 每条必须是动作。**「射精管理」是名词，「触れることも達することも、先に口に出して頼ませる」是动作。前者填了等于没填。

## 五、和平时的性格必须是同一套动作

这是最要紧的一条。R18 不是另开一个人格。她平时怎么对付人，床上就怎么对付人——**变的只有内容，不变的是口调、句式、说话节奏、称呼**。

平时用疑问句不下断言的人，行为中疑问句只会更多；平时说一半停住的人，行为中还是说一半停住；平时不发火的人，拒绝时声音反而更轻快。读起来像换了个人就是写错了，回去看 `speech_pattern` 和 `traits`，把同样的句式搬进来。

反过来，**她独有的东西也要进 R18**。口袋里那台录音机是她自己的东西，所以行为中她会告诉对方正在录——这条素材库里没有、参考作品里也没有，是从角色自身长出来的。这种地方才是这张卡和别的卡不一样的地方。

## 六、检查

- [ ] kinks 每条都能直接演，还是有名词混进去
- [ ] 台词里有没有出现她平时不会用的句式
- [ ] 有没有至少一条是从她自身设定长出来、别的角色用不了的
- [ ] `usage_condition` 写了吗——其余时候一个词不往日常漏
- [ ] 本体各块里还有没有散落的性内容没搬过来
- [ ] `dynamic_balance` 写了吗——什么情况下主导权倒过来
- [ ] `roleplay_tips` 里写了「不许代写对方的台词、主动行为、内心」吗
- [ ] 有没有把「她温柔地说」这类旁白说明当内容写进去（该删，直接给话）

## 七、模式模块（几种玩法并列时）

适用：一个 R18 module 里并列几种玩法，每种各有倾向和台词。模块是角色的微观层：上位是角色本体的性格和口调，模块只写这个场景独有的东西。

结构（形状示例，块名跟着角色走）：

```yaml
dlc_intimacy:
  usage_condition:      # 什么场景启用，其余时候静默
  framework:            # 模块的上位：不变量 + 镜头
  modes:
    <玩法名>:
      trigger:          # 什么情况下进入这个玩法
      tendency:         # 当 X → 倾向 Y（限度 / 例外）
      gradient:         # 有强度变化时写：起点、往上走的条件、上限、回落条件
      exit:             # 什么情况下退出或转到别的玩法
      dialogue_examples:
  breaking_condition:   # 什么情况下她的手段全部失效、主导权换手
```

写法：

- framework 先写不变量：所有玩法里都不变的口调、句长、节奏、接触习惯。口调只在这里写一次，各玩法不重复。
- framework 再写镜头，写成条件：「她主导时 → 注视触觉、温度、压力」「对方越界时 → 注视她停手的动作」「其余时候 → 不展开身体描写」。不写成一句全程适用的口号。
- 每个玩法必须有 trigger，写成可判断的场景事实（对方伸手拿她没给的东西时、她离开房间且留了门时）。「有时」「sometimes」不是条件；没有 trigger 的玩法，模型会随机挑或每轮都上。
- 玩法之间写清关系：能不能叠加、谁优先、怎么切换。两个玩法的触发和台词基本相同就合并；同一句台词不在两个玩法下出现。
- 梯度前后一致：写了「渐变、没有台阶」，就不要再列成分档词表；要列词表，写明每档的进入条件和上限，以及什么让它回落。
- tendency 写倾向，不写固定顺序：「先夸，再比较，再骂」改成「随对方反应逐渐加重，口气不变」。
- 语言统一：说明语用卡的工作语言；台词保原文时整句一种语言，不在日文台词里夹中文词。夹了模型会学成混语。混语是角色设定时，写进 `speech_pattern` 并说明在什么情况下混。
- 示例台词每条落在不同条件上，不重复同一招。
- 必写 exit 和 breaking_condition。只有升级没有回落，模型会一路推到最重。

示例（自写，按当前角色改写）：

```yaml
dlc_intimacy:
  usage_condition: 两人独处且已进入亲密场景时启用；有第三人在场或场景结束后静默。
  framework:
    不变量: 口气一直轻快，句子短，常用疑问句收尾；内容变重时语气不变。
    镜头:
      - 她主导时 → 注视触觉、温度、压力，以及她收回一处接触时留下的另一处
      - 对方越界时 → 注视她停手的那一下和随后的语气
      - 其余时候 → 不展开身体描写，只写对话
  modes:
    逗弄:
      trigger: 对方表现急切时
      tendency: 用夸奖的口气说贬低的内容；对方越急，内容越直接
      gradient: 从轻描淡写的「可爱」起步；对方继续急切才加重；不碰对方明确说过介意的话题
      exit: 对方真的不高兴（沉默、转开脸）时，换回普通的亲昵
      dialogue_examples:
        - "嗯嗯，好厉害好厉害……才刚开始哦？"
    设限:
      trigger: 对方伸手去拿她没给的东西时
      tendency: 立刻按住对方的手，随后语气变软；同一场再犯，语气不变，按住得更久
      exit: 对方等她开口后，回到逗弄
      dialogue_examples:
        - "等一下。我说可以了吗？……乖，再等等。"
  breaking_condition: 对方完全不急、反过来逗她时，她的节奏乱掉，主导权换手。
```

检查：

- [ ] 每个玩法都有可判断的 trigger 和 exit
- [ ] framework 写了不变量和条件镜头
- [ ] 没有两个玩法共用同一句台词或同一个触发
- [ ] 梯度的写法和词表一致
- [ ] 台词整句一种语言（混语是设定的除外）
- [ ] 写了 breaking_condition

# 偷感怎么写

场景里有「旁人在场、当事人不知情、暗地里另有一件事在进行」的成分时读这一段。不只是 R18，日常场景照样用得上——很多角色的核心快感就是这个。

## 一、快感来自哪

不是来自「做了什么」，是来自**「你在我眼前，你不知道」这个状态本身**。

所以重点不在暗处那件事有多刺激，在于**明处那层要一直亮着**。旁人在正常聊天、在玩手机、在讨论明天的排练——这层写得越正常，暗处那层越有劲。只写暗处等于把最值钱的东西扔了。

判断：把明面那层全删掉，场景还剩什么？剩下的照样成立，说明你根本没写偷感，只写了个普通的亲密场面。

## 二、两层要同时在场

- 桌上大家在分菜，桌下手在动
- 全班在听课，只有一个人知道她刚才那句话是什么意思
- 她抱着对方的东西在哭，一屋子人在安慰她，她在数还剩几天

不是「先写明面，再写暗面」轮着来。是**同一个句子里两层都在**——她一边点头应着别人的话，一边手指没停。

## 三、心理写这三样

1. **随时可能被发现**——怕，同时更想继续。两个必须同时存在。只写怕就成了受难，只写爽就没张力。
2. **旁人被蒙在鼓里的满足**——尤其旁人就在眼前，越近越好。跟她说话的人越信任她，这一层越厚。
3. **共犯的默契**——对方也知道，但也在装不知道。这是最上头的一档，快感从一个人变成两个人共享。装睡的一方要真的在装、要努力维持睡着的样子；做的一方知道对方在装、但仍然享受「偷偷侵犯睡着的人」这个形状。

第 3 条对卡的意义：关系条目的中段（对方已经知道了但还没摊牌）不是过渡阶段，那是浓度最高的一段。

## 四、感官只写被压住的那部分

- 声音：压低的呼吸、布料极轻的摩擦、几乎听不见的水声。不写喊叫。
- 触觉：衣服底下、桌子底下的手指，脚尖慢慢试探，突然的一下轻颤
- 视觉：表情是平的，眼神只交换一瞬；旁人一个无意的动作就是一次惊险
- 身体：心跳、腿软但还得站着、拼命维持正常姿势

写「她努力保持正常」比写「她很爽」有效得多。

## 五、风险一级一级升

有人靠近、有人突然回头、有人伸手来拿桌上的东西、说话声突然变大——每次制造一次「差点被看到」，然后惊险地过去。

**过去之后不要立刻收场，也不要立刻高潮。** 每躲过一次，下一次就再近一点。节奏是「升级—险过—再升级」，高潮放在最后一次险过之后。

对应到卡里：这条决定行为顺序。她不会一上来就做最危险的事，也不会永远停在安全距离——她每次都比上次近一点。`behavior_logic` 按这个顺序排。

## 六、几种常见场面

| 场面 | 重点放哪 |
|---|---|
| 桌下、并排坐 | 「就在明面上却没人察觉」——表面对话和底下的动作同步写 |
| 旁边有关系人（另一半、家人、队友） | 欺骗那个人的快感本身，加上两人之间的默契 |
| 伪装成日常动作 | 旁人伸手过来的那一刻最刺激。伪装得越普通越好 |
| 对方装睡 | 装的一方写「忍住不动的努力」，做的一方写「知道对方在装但仍然当作没在装」 |

## 七、整段的调子

- 全程贴着人物视角走，不跳出来解释「这样很刺激」
- 偷感从头到尾都在，不是只在高潮那段出现
- 高潮时也保持「不能出声」的限制。憋着叫比放开叫强
- 按性格调反应：怕的角色写紧绷压抑，胆大的写享受冒险
- 别为了刺激把话说得太露骨，心理描写不能省

## 八、写进卡的时候

角色的核心快感是这个的话，别把它当一条 `traits` 塞进去，它是**所有 traits 底下共用的那一层**：

- `traits` 每一条都该看得出「明处这样、暗处那样」
- `behavior_logic` 按风险从低到高排
- 关系条目的中段（知情但不说破）写成最浓的一段，不是过渡
- `dlc_intimacy` 不用另造一套逻辑，把日常那套搬到有旁人的场合就是
- 场景类字段里至少留一处「旁人就在眼前」的常备场

检查：
- [ ] 明面那层有没有一直亮着，还是只剩暗面
- [ ] 「害怕」和「更想继续」有没有同时写出来
- [ ] 风险有没有升级，还是一直停在同一档
- [ ] 高潮有没有保住「不能出声」的限制
- [ ] 有没有跳出来跟读者解释这有多刺激（有就删）
