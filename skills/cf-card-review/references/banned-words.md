# 八股行话与具体行为替换表

核心判据：**把这句话念给不懂行话的人听，对方能立刻看见人物的动作与画面，才算立住了。**

汇报与写卡同样遵循这一标准。想不出花哨说法时直接用平实通顺的现代汉语写出人物说了什么、做了什么。

特例保留：词汇本身就是角色身份的原生思维方式时自然保留，例如演员角色想「配役」、将领想「压制」、赌徒想「筹码」。

## 准确使用人格专业术语，省去错位跨行黑话

`personality` 类型学字段使用各自系统的准确原生术语：MBTI、九型、Socionics、Attitudinal、SLOAN 直接写准（如 `Limbic`、`4L`、`Fe主`），并在后面紧接一件该角色实际会做的具体反应：

| 空泛套定义 | 专业术语 + 具体行为画面 |
|---|---|
| `Se三 = 享受当下的刺激` | `Se三 = 现场出现突发岔子时能顺嘴圆成既定安排，遇到肢体冲突则第一时间退开` |
| `内侧 Limbic = 情绪不稳定` | `内里是 Limbic，一旦察觉关键把柄脱离掌控，手指会瞬间僵住、半晌接不上话` |
| `Ti劣 = 逻辑能力较弱` | `Ti劣 = 对方把前后事实一条条摊开对质时便词穷理屈，转而把话题拉回人情与态度上` |

## 具体改写对照

| 八股抽象句 | 有画面的具体写法 |
|---|---|
| 她的温柔成了让人欠债的凭据 | 她俯身替对方系好左脚鞋带，顺手把右脚那根悄悄松开半寸 |
| 制造信息非对称来掌握主动 | 只把这件事悄悄告诉对方一人，让对方觉得彼此共享着秘密 |
| 表面的笑脸只是营业商品 | 有外人在场时总是弯着眼角应和，等人走远了便垂下眼皮歇神 |
| 伪装的假面被当场撕开 | 一直藏着掖着的小心思被人迎面点破 |
| 把眼泪当成操控人心的武器 | 先红着眼眶掉下泪来，等对方心软开口替她拿主意 |
| 脑海里的回路瞬间切换 | 话音戛然而止，垂下眼帘沉默片刻 |

## 两面性角色的写法

写内外有别的复杂人物时，直接分别写出她在不同场合的具体言行（「在众人面前如何应对，两人独处时如何流露」）。许多角色的公开表现与私下盘算同时出于真心：当众落泪时确实觉得委屈，掉泪的同时也确实在留意心上人的神色。直接写出两层并存的行为，人物比贴一个「假面」标签立体得多。

## 把程度形容词落实为可观察行为

| 模糊形容词 | 可执行的具体表现 |
|---|---|
| 待人很热情 | 每次打招呼先笑着迎上半步，话尾常主动抛一个关心对方近况的问题 |
| 性格有点傲娇 | 被夸奖时先偏过头顶回一句，等对方不说话了又小声答应帮忙 |
| 说话比较优雅 | 遣词完整和缓，情绪起伏时也保持平稳语速，少用感叹号与俚语 |

## 使用行业词汇时分清内部本义

需要使用角色所属行业的专业词时，按业内真实分工写准：

| 词汇 | 实际指向 | 关注重心 |
|---|---|---|
| **经营管理** | 统筹预算、排定路线、处理公关风波、调配人事 | 让团队运转存续并盈利 |
| **舞台营业** | 打磨演出表现、回应观众期待、维持台前风采 | 赢得舞台认可与喜爱 |

例如有的偶像角色对经营管理毫不在意，却对舞台营业苛求到极致，分开写清才能立住真实的人物性格。

## 区分认知倾向与现实能力

`core_stack` 九项描述的是人物感知世界与做决定的心理习惯：

- `so`（社交本能）体现为对群体关系冷暖与人际连带的敏锐留心；
- `sp`（自保本能）体现为优先守住个人生活边界、精力与安全垫；
- `Ti` 劣势体现为面对冷冰冰的条理诘问时容易局促，习惯把问题拉回熟稔的情感与经验主场；
- 九型 `3` 号看重看得见的肯定与成败体面，`2` 号看重被在意之人需要与偏爱；
- `Choleric` 体现为目标锁定后行动力外放、步调急促。

动笔后用一件「她平时会做的具体小事」检验该条分析，能对上画面即说明抓准了人物。
