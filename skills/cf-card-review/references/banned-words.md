# 不许用的词

判据只有一条：**把这句话念给完全不懂这行的人听，他能不能立刻看见画面。看不见就是八股。**

跟用户汇报的时候同样算数。规矩只在卡里生效、一开口聊天就满嘴「机制」「双重结构」，那是没学会。

想不出更好的说法就用最普通的大白话。**写不出画面的漂亮句子，价值低于写得出画面的笨句子。**

例外：这个词本来就是角色自己的思维方式。演戏系角色说「配役」、军人说「制圧」、赌徒说「賭け金」，那是角色在想事情，不是作者在偷懒。

## 禁的不是术语，是拿别行的词描述人心

黑名单针对的是把人写成货物、机器、账本。**不是让你少用专业词。**

`personality` 那几个字段本来就该用术语——MBTI、九型、Socionics、Attitudinal、SLOAN 是这些字段的原生词汇，要用，而且要用准。Limbic 就写 Limbic，别改写成「敏感型的人」；4L 就写 4L，别写成「不擅长讲道理」。术语被削成大白话，等于把索引删了，模型认不出你在说哪个系统。

真正决定有没有画面的不是词汇通俗，是后面接不接得上一件她做过的事：

| ✗ 术语 + 通用定义 | ✓ 术语 + 她做过的事 |
|---|---|
| Se三番＝その場の刺激を楽しむ | Se三＝直播事故秒级圆成「演出」的现场即应。但不做身体层面的对抗 |
| 内側は Limbic で情緒不安定 | 内里是 Limbic。发现录音脱离掌控的瞬间僵住的那个反应，才是底色 |
| Ti劣勢＝論理が苦手 | Ti劣＝只用事实和矛盾按顺序排出来，她没有还手的招。她自己那套「理论」也是借来的，一推就塌 |

左边换成大白话照样没画面，右边留着术语画面也在。缺的从来是那件事。

## 「面具」这一类要单独说

写两面性角色时最容易滑进「面具／仮面／ペルソナ／表の顔と裏の顔」。它的毛病不只是八股，它会把角色写错。

面具是可以摘的，摘下来那个才是真的。但很多角色的两面**同时都是真的**——她当众哭是真的在哭，同一时间也真的在准备下一步。一旦写成「面具」，读的人就会去找「哪个是真正的她」，而正确答案本来是「都是」。写成「商品」更糟，那是把人变成货架上的东西。

改法：不写她戴着什么，写她在谁面前做什么。「人前ではこうする、二人になるとこうする」——两句就够。

## 形容词一律换成具体行为

| ✗ | ✓ |
|---|---|
| 要热情 | 每次回复结尾抛一个问题 |
| 有点傲娇 | 被夸时先反驳一句再小声接受 |
| 说话优雅 | 不用缩略语，句子结构完整，不用感叹号 |

出卡前搜一遍「要／很／比较／有点／往往」，全部改写。

同时禁：比喻和类比、定义内心感受、假设性词汇（会／觉得／倾向／可能／如果／有时）、把人写成数据和机器。

## 用了某行的词就得知道那行内部的区分

混用会直接写错人设。

| 词 | 指什么 | 目的 |
|---|---|---|
| **経営** | 管资源、定路线、处理危机、管人事 | 让团体活下去、赚到钱 |
| **営業** | 出内容、跟粉丝互动、维护公众形象 | 吸粉 |

「事业心」这种合起来的说法禁用。真实存在的情况是：对経営毫无兴趣（团散了也无所谓、成员退出也不心疼），但对営業上心到病态。合成一个词来写，角色直接废掉。

不确定某个词在那一行里具体指什么，就别用，换大白话。

## 性格系统的结论不许写成能力或成就

core_stack 九项测的是性格，不是能力，也不是成就。

so 不等于有事业心、擅长管理，它是对人际关系的感知力（谁跟谁好、动谁能让谁疼）；sp 不等于会理财，是怕被侵入所以先筑墙；Ti 劣势不等于笨，是不靠纯逻辑解决问题、被事实顶住时把话题拖回自己的主场；3 号要的是看得见的承认（名次、地位、赢），2 号要的是看不见的承认（被需要）；Choleric 不是脾气差，是能量向外、锁定目标。

自查：把这一项的结论换成一句「她做过的事」。换不出来，说明在套定义而不是在读角色。
