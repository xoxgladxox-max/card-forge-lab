# 成文检查规则集（v2.14.2）

总规则：

- 只查文字。JSON 字段、触发、递归、位置、深度属于世界书机制校验，另做，不混成一关。
- 操作成功或格式通过不等于内容逻辑通过。
- 看不到料源或作者确认时，不判定事实真假：列为待核，该细节停止进卡。一处无据只影响该细节及可证明受影响的内容。
- 局部检查不推翻上层已确认的内容。先核对规则层级、当前阶段、对象和字段、证据准入，再查正文。

## 何时调用

| 时机 | 做什么 |
|---|---|
| 写卡前（资料够了、准备成卡） | 缺口与方向检查；资料明显不足时先停，不用检查把未知填满 |
| 写卡中（每完成一个大模块） | 复查受影响部分：新增设定、改核心性格、调关系、拆世界书条目时 |
| 交付前 | S 组、C 组全量查；未通过不算完成 |
| 跑卡中（复读、跑偏、设定不生效、状态栏过载） | 先把问题归到文本、结构、触发机制或模型表现，再决定改哪一层 |
| 跑卡每段 | writer 自查 S 组重点和 C1、C7；linter 全量扫两组 |

## 检查顺序

从上往下定范围，从下往上验归属。上位概念、关键词、tag 是审查顺序，不是要加进卡里的字段。

1. 上位概念：这条内容属于人格、外貌、语言、关系、世界规则、地点、角色、事件、状态还是成人模块？
2. 关键词与 tag：作者想让模型偏向哪个方向？只留作者确认过的方向，不把标签的常见联想当成设定。
3. 具体细节：只补作者想锁定、且正文能调用的语言、动作、选择、限制或结果。越往下写，可保留的可能越少。
4. 反向复查：细节是否属于上位概念、是否带来新信息、是否有依据、是否近义重复、是否把开放倾向写成固定流程。
5. 归属与重复：同一内容可以跨容器出现，但每处要承担不同功能。对特定对象成立的归关系，对全局成立的归全局块。重要的内容（核心体验、硬规则、模型容易忽略的限制）在不同位置重复三次左右，不那么重要的设定只在主归属处写一次，具体重复次数按重要程度取舍；重要内容只写一次或一般设定反复出现，都标出来。
6. 概念作用：每个设定至少改变语言、行为、选择、关系、场景或可追踪状态之一；没有作用的名词、字段、细节删掉。

## 报告格式

每轮只报差异，不重贴全文：

```text
本轮查项：
问题 N 处：
- 位置：
- 问题：
- before → after：
存疑待定：
通过条件：
```

- `before → after` 只在已获准修改时填；要作者决定的放进「存疑待定」，不擅自改稿。
- 问题分类：缺资料、归属错误、重复注水、过度收窄、固定流程、技术失效、模型表现偏差、上游缺陷。不统称为写得不好。
- 上游缺陷：正文的错来自规划、结构、料源索引、模版、任务书或验收本身（例：C11 命中，通常是结构里没给原作基底留位置）。写明最高出错层，交回上游，不给正文 before → after。
- 检查是内审，不要求作者重读全文。

## S 组：静态规则（文本搜索可判定）

完整词表在 `references/banned-words.md`，本表只列检法。

| 编号 | 规则 | 检法 |
|---|---|---|
| S1 | 外语残留 | 输出语言为中文时，搜 ちゃん/です/ます/さん/くん 及整句外语；歌名与专有名词豁免 |
| S2 | 机械八股词 | 搜「机械」「拉扯」「张力」「撕裂」；规则文本中改「死板照抄」，正文中改具体动作 |
| S3 | 电报体成行 | 搜独立成段的 ≤6 字短句（「截然相反。」「线索彻底断了。」类）；并入长句 |
| S4 | 廉价通感隐喻 | 搜 糖/蜜/毒 作喻体的句子 |
| S5 | 心理学后设术语 | 搜 斯德哥尔摩/PUA/煤气灯/操纵/人设面具/假面 等学术与后设词 |
| S6 | AI 八股生理反应 | 搜 瞳孔收缩/瞳孔骤缩/指甲嵌进掌心/胃袋失重/喉结滚动 |
| S7 | 口癖复用 | 同一输出内「微微」≥3 次、同一小动作（摸口袋等）≥2 次、同一道具场景复用 |
| S8 | 空洞程度词 | 搜 要/很/比较/有点 修饰的形容词（卡文本适用），换可执行行为 |
| S9 | 保守回避词 | NSFW 块内搜「安全裤」等回避性替代词 |
| S10 | 世界书关键词泄漏 | 正文中搜当前卡世界书的触发词与条目内部术语原文 |
| S11 | 财务与说明文腔 | 搜 账本/记账/欠账/收支/债务 及医学、统计、报告式措辞；场景本身设在该领域时豁免 |
| S12 | 世界节点角色痕迹 | 只扫世界、地点、规则、背景设定的正文：搜本卡各角色的名字与关键词，以及 穿越/身世/出身/性格/喜欢/讨厌/口癖/战力/数值/面板/好感/心理 等个人向字样；命中只做标记，逐条交 C12 判 |
| S13 | AI 套话 | 搜 不禁/油然而生/仿佛/宛如/这一刻/值得注意的是；改成具体动作或直接删掉，角色台词里本来就这么说的豁免 |
| S14 | 「的」字堆叠 | 开场白和正文里一句话「的」超过两个，或出现「的的」；合并修饰（「他的红色的大衣」→「他那件红大衣」） |
| S15 | 无意义的「不是 X」 | 搜「不是……」先否定一个没人提过的东西再说真正的东西（「一声巨响，不是雷声」）；删掉否定半句，直接写是什么。否定的是剧中人刚说过或认定的事时不算 |

命中后先看上下文再报。三类豁免：

1. 禁令句本身（「严禁使用糖/蜜/毒」不是违规）。
2. 专有名词与原作设定（「机械熊耳头饰」）。
3. 描述注意力去向的合规词（「倾向呈现」「会」）。

## C 组：语境规则（读上下文判断）

| 编号 | 规则 | 判据 |
|---|---|---|
| C1 | 代写 {{user}} | 是否写了 {{user}} 的心理、推理、决策、连续台词；有则删，改为 {{char}} 可观察到的言行 |
| C2 | 上帝视角拆解 | 是否用叙述者口吻直接解说人物动机机制；改为落到具体言行 |
| C3 | 推理空间写死 | 悬念是否被当轮解答完；只留触点 |
| C4 | 称呼/语体档位 | 卡定义了多档自称或语体时，是否与场景匹配 |
| C5 | boundaries 违例 | 是否违反当前卡角色的 boundaries 声明 |
| C6 | 节奏跳级 | 冲突或亲密强度是否跳过铺垫直达高强度（含特化块声明的分级门槛） |
| C7 | 结尾越权 | 末段是否替 {{user}} 接话或预设其反应 |
| C8 | 静默渗漏 | 特化文风块未激活时，其词汇、话术、癖好倾向是否渗入 |
| C9 | 信息倾倒 | 配角是否像复述世界书条目一样倒设定 |
| C10 | 数值无因果 | 状态栏数值变动是否有正文事件支撑 |
| C11 | 基底立足度 | 衍生、IF、特异题材：遮掉分支改动和本线独有规则后，剩下的能否撑起原作世界的普通日常场景？地理格局、运转法则、核心物种（不止分支出场的那种）、常态社会缺项就不过。按上游缺陷归因 |
| C12 | 世界越界写角色 | 世界、地点、规则、背景设定里的角色，是否只以势力或事件主导者身份一句带过？写了身世、面板、性格好恶、私密互动就是越界，移到角色设定。反向同查：角色设定是否复述世界法则 |
| C13 | 开场白前提无出处 | 开场白交代的处境、起因、身体状态、时间压力，是否都能在原作或已确认设定里找到出处？找不到就改成开放写法（例：「送来得比平常晚」，不定死原因），不替 {{user}} 预设走向 |
| C14 | 句式在一组条目里复现 | 同组条目（配角群、同层地点）里同一句子骨架是否反复出现（例：「某人不知道 X」多次）？卡里或全局写明的禁用句式，每写完一条就扫一遍 |
| C15 | 同时加载能分清 | 几条同类条目（地点、配角、文风）同时加载时，只看正文能否分清各是谁、哪儿？包裹的 name、part 与标题要对得上；先跑 `check`，P18 系列无警告再读正文 |
| C16 | 秘密与暗示 | 角色卡和常驻条目里有没有「隐瞒」「另有身份」「真相是」「实际上」这类写法？秘密只写一处，放默认关闭条目；角色不知道的事卡里不出现。规则改动后先按新规则审一遍所有常驻条目 |
| C17 | 事实依据与准入 | 每条原作事实能否回到具体料源或作者明确确认？旧卡只作线索、不作证据；无正向依据就不写入，不要求先证明原作不存在。看不到来源时列待核，停止该细节 |
| C18 | 纠错范围不过界 | 是否只改已确认的具体错误及其可证影响范围？保留独立有据、已确认且不受影响的内容；不因一处无据否定整块。重开已确认节点先得作者同意 |
| C19 | 通用槽位与空话 | 是否套了 `name` / `definition` / `description` 固定槽位，而不是条目名和方面名作 key？定义是否只复述名字？描述是否只讲往事、对当下无作用？逐句问「删掉它，玩卡时写出的内容会不会变」，不会变的标出，按重复注水归类；数值、限度、例外、作者明确指定的单卡特例或硬禁令不删。同查上下位拆分：上位总纲是否塞入了已有独立下位专项条目的细节，是否把一两句话的零碎设定拆成了空壳条目，或把占常驻篇幅的大批同类简短设定全堆在常驻总纲里而未合进下位同类条目。同查指向其他条目的无意义元信息：标题或正文里写「（具体道具功能详见绿灯道具条目）」「由对应绿灯条目按需触发」这类指引说明的（绿灯条目靠关键词触发，有就会触发，不需要多说一句），按空话删除，本条确实需要的设定直接写清。抽象概念近义词要合并，但微观模块里供五感描写轮换调用的具象质感词池（材质、光泽、动态、温湿度、气味、拟声）与按不同动作/部位切面给出的示例豁免。同查上下位：规则条件里写了具体身份、例子只停在上位概念、几个例子挤在同一种组合上，都标出来。改法按 `cf-card-refine` |
| C20 | 写卡备忘留在正文 | 正文里有没有写给写卡人看的取舍说明（「不用某某的推测」「按某卷的说法」「以官方为准」「旧稿写错已改」「待确认」、`*_guide` 字段）？挪到 `## 工序` 或 `note/`，正文只写备忘背后的结论；人物猜测对扮演有用时，写进该人物节点并标【角色说法】 |
| C21 | 场外比喻进卡 | 作者沟通时用的类比、吐槽、举例（「就像充电宝」「像吃正餐和喝粥」）是否原样进了世界条目、角色设定或文风？对照作者原话查；命中就只留背后的机制（条件、档位、限度、例外）。优先级：只用现成概念和圈内通用词、不造词、平实克制说明，高于「禁止把对话直接写进卡里」；对话里本来就是现成概念、圈内通用词或平实清楚的机制说明时直接保留，不为避嫌换生僻词或造新词。作者明确要保留为某角色口头禅的豁免 |
| C22 | 自造词 | 概念名、方面名、标签里有没有只在本卡出现的四字伪成语或复合新词？能在 Pixiv、百科或搜索引擎搜到同义用法的算现成词。命中换成现成概念或圈内 tag；没有就改成「条件 → 结果」的平实句子。作品术语和作者指定保留的词豁免 |
| C23 | 上位缺席与锁死路径 | 每条规则的第一句是不是上位原则？一上来就列具体禁词、部位、动作的标出。依赖未知感与临场发挥的概念型法则（未知代价、认知异常、禁忌反噬等）是否被过度展开成了固定异象打卡清单或全员统一的态度档位表（应只留上位分类与一句核心定位，应验方式与各人反应留白）？特化与感官文风的一二层是否作为常驻蓝灯保持纯上位（不含具体部位与具体反应），不同职责的下位专项是否拆成各自独立的条件绿灯（不混写进同一条）？第三层是否严格按「全景 / 中距 / 近距 / 微观」四档独立颗粒度（不两两合并）写出规律并用 `(e.g., ... 实际发展按角色性格与实际情况进行推进)` 避免了固定动作打卡？第四层词池是否用 `e.g., ... etc.` 写成开放的语感刻度（允许按现场派生新词，不写成闭合死名单）？持续生效的规则是否写成了动作顺序或必然触发的剧本？改成「当 X → 倾向 Y（限度 / 例外 Z）」，条目名与方面名作自定义 key。 |
| C24 | 文风分层与镜头 | 宏观（基底文风）和微观（特化 / DLC 文风）分开了吗？微观有没有可判断的启用和退出条件，有没有重写宏观的语体、视角、禁令？镜头是否写成「当 X → 注视 Y（限度：Z），不是 X 时不展开」，在「全景 ↔ 中距 ↔ 近距 ↔ 微观」四级之间支持双向推拉、承接上轮起点（不强求每轮退回全景或单轮写满四级），并保持远宽近细四档独立颗粒度与感官聚焦、情感聚焦双轴独立、不跳级？正文里镜头是否在每场平均分配（赶路也写身材、亲密场景插无关环境）？微观退出后其意象、词池和命名是否还在出现（同查 C8） |
| C25 | 信息边界 | 秘密、传闻、未公开的真相在表面条目里有没有 `知情` 方面？`知情` 是否复述了真相（真相只该在 `揭晓/`）？正文里有没有角色说破或据此反应了自己不该知道的事？揭晓后 `知情` 有没有同步 |
| C26 | 基准段与末尾语态 | 宏观文风有没有样例段，样例段是否按宏观的全部要求写、有没有代写 {{user}}？开场白和样例段语感是否一致？离最新对话最近的注入（@Depth、文风块末尾）是正文语态还是长表格和规则？正文是否照搬了样例段的句子和意象（同查 S7） |


终审发现的新问题，按「编号 + 规则 + 检法」追加到对应组，不写案例长文。S 组新增编号要同步 `src/lib/lint-rules.mjs`（测试会核对两边编号一致）。
