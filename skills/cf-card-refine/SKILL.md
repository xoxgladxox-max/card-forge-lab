# 精炼卡文本（v1.18.0）

## 总规则

- **每修一块前先写出明确判断**：动笔改写前，先用两三句话写出明确判断，说明原稿这段写法在扮演中会引发什么具体毛病（如注意力被禁令带偏、路径锁死、跨层复读或括号传染）、哪些属于固定锚点要写准、哪些属于开放方向要留出弹性。
- **一句一用**：逐句检验「这句在玩卡时会怎样改变模型的输出」，把起作用的句子写成清晰的「当满足某条件时 → 产生什么结果（适用范围与例外）」，完整保留数值、阈值与边界条件。
- **保护作者确认的单卡特例与模块骨架**：作者明确指定的单卡偏好保留原意；已确认的顶层与中层模块结构（如角色专属模块 `about_xxx`、独立阶段 `module` 或阶段 `event` 条目）保持完整，遇到跨块重复时按各块唯一主归属清理越界复述。
- **正向表达、现成词汇与剥离场外比喻**：优先选用成熟流派、心理学与圈内通用 tag（如傲娇、人外娘、寸止），没有现成词时用自然通顺的现代汉语陈述句直接写出条件与结果；作者沟通中的场外类比只提炼背后的运作条件与档位，对话里本就准确平实的现成概念则直接沿用。
- **全卡统一区分「本我内核与硬锚点」和「语料库可能性空间」**：
  - **本我内核与硬规矩（写准闭合）**：时代地理与客观规则维度、习俗标准步骤与边界；角色底层身份、认知滤镜、核心欲望执念、静态外貌感官、说话习惯与关系底线；受限跟拍视角盲区与状态栏阶段锚点。
  - **可能性空间与现场派生（给条件光谱与采样）**：风俗个体反应与特殊场合变体、概念型法则应验；角色穿搭变体、日常同行活动、试探与冲突反应、亲密表现采样；镜头具体动作与感官参考词例。统一先写一句上位原则，再用 **「平时/通常……」「有时……」「一些人/一些情况下……还有一些……例如……」「在特殊场合/特殊情况下……」** 给出采样并声明供模型现场自由派生。
- **专项机制去剧本化与连续梯度**：把通用机制里夹带的单人分镜小动作、默认主角宗师模板或单向必败滑坡剥离干净，改为「决定胜负的动态变量维度 + 双向开放结果（稳控守成与动摇失守并存） + 连续梯度（三阶缓冲替代二值开关）」。
- **单模块修改范围与三步精修方案**：
  - 每次专注精修当前指定的 **1 个独立模块或条目**，输出 `位置 + 明确判断 + before → after` 供作者确认。
  - **Unit 1 判定文体与主归属**：先确认当前文本属于「平实设定说明 / 角色纯口语台词 / 文风指导规则 / RP 小说正文」，核对唯一主归属并写出诊断判断。
  - **Unit 2 转为纯净正向表达**：删去复述名字的空洞定义、将否定对比句改为正面直接陈述、清除虚空防御句与句内冗余括号、松绑非必要的排他词、剥离场外比喻。
  - **Unit 3 校准锚点弹性与全书回查**：固定锚点写实，随境变体改用开放方向句式；涉及常驻蓝灯改名或通用池剥离时，同步核对常驻层零泄漏与下位单点归属无遗漏。

## 世界书条目精修

- **事物本名作 key，自然方面展开**：直接以条目名称作顶层 key，下一层按该事物的实际运作方面展开，把历史往事转化为当下仍在生效的规矩、格局或隐患，把抽象评价词换为可观察的具体结果。
- **常驻泛用替换与全量同步**：从 `description.md`、常驻 `world / rule`、宏观 `style`、`output` 状态栏或 `<thinking>` 移出具体角色名、器物名或支线专名前，先替换为通顺的上位泛用类别词（如「在场人物」「不同渊源的异类族群」「遵循当前激活条目的专属规则与成立门槛」）；修改核心概念称谓时同步更新常驻蓝灯与下位 `keys`。
- **剥离后的单点归属回查**：把原混在通用物种或规则池里的单角色独门绝活、专属器物剥离出来后，立即回查对应角色的 `character` 条目，确认该独有设定已在主归属位置完整落位。
- **排他词松绑**：排查正文中锁死单一路径的排他限定句（如把某种条件写成唯一触发前提），除确实不可替代的硬性底线外，改为「当……时」「可通过……或……达成」等正向条件句，保留合理的破局与互动空间。
- **按事物本性组织专项结构**：物种条目聚焦客观生理硬件与泛用生态习性；器物与术法先写正统本职功用，再把衍生与欢好用法放入开放举例；社会风俗按「日常规矩 → 标准过程 → 常见细节与个体差异 → 描写关注点」展开。

示例（正向条件与例外）：

```yaml
区域宵禁:
  定位: 区域每晚执行的夜间通行制度。
  信号: 日落后一刻由管理员发出九次钟声信号；遇恶劣天气提前至日落时分发出。
  通行规矩: 信号发出后居民留驻各自院落；因公务在区域内走动时携带照明灯火，未携灯者由巡夜人员护送返回住处。
  通行特例: 医护救治与运送应急物资的人员登记后可夜间出入。
```

## 剥离场外比喻

作者沟通时所用的现代类比（「就像充电宝」「像吃正餐和喝粥」）只提取背后的条件、恢复幅度与限度写进正文：

```yaml
# before：场外比喻直接进卡
月光: 满月是快充，新月是涓涓细流。

# after：提炼客观机制与限度
月光:
  恢复: 沐浴月光时恢复体力；满月之夜可在一宿内回满，新月之夜恢复微弱。
  限度: 隔着厚云层或琉璃窗时效果减半，白昼时段自然休止。
```

## 使用现成概念，保持零句尾贴标括号

优先采用成熟概念与圈内通用 tag 作结构键名，值直接写纯净的可观察言行，省去句内破折号与句尾打括号贴标签：

```yaml
# before：自造四字词拼接，或句尾打括号贴标签
情绪: 冷面回温 / 被夸时先冷后热（傲娇）。

# after：通用 tag 作键，值写纯净的可观察言行
傲娇:
  语言: 被当面夸奖时先板起脸反驳两句，等话题揭过又小声哼着默认。
  行为: 嘴上嫌弃麻烦，手头却提前把对方要用的器物擦拭妥当。
```

## 先立上位原则，再用正向写法落细节（清除虚空防御）

每条规则第一句先定正面总方向，随后展开具体做法；删去旧稿残留的靶向禁令与复读禁用词的负面清单，避免粉红大象效应把模型注意力引向坏词：

```yaml
# before：靠点名负面词和否定句堆砌规则
描写: 禁用「眼底闪过一丝」，忌用齿轮、引擎形容心情。

# after：先立正面原则，再给出可执行的具体写法
情绪与神态白描: 通过人物当下的呼吸深浅、视线停顿、指尖松紧与说话语速展现心绪起伏；心理活动贴合人物自身的身份阅历与日常起居经验选词。
```

## 清理写卡备忘

正文只保留面向扮演模型的最终设定结论；取舍缘由与考据过程归入 `记录/决策记录.md`：

```yaml
# before：正文残留写卡备忘
区域宵禁:
  description_guide: 不用区域负责人的说法，按管理员日志写
  信号: 恶劣天气照常。

# after：备忘归入记录，正文直接写清客观事实
区域宵禁:
  信号: 恶劣天气提前至日落时发出；信号变更权归属管理员。
```

## 规则写上位，例子写下位

跨角色倾向与风俗条目在条件层使用上位类别与关系维度（如年长对年幼、引路人对初来者），具体情境放入 `例子` 并保持表达干净：

```yaml
护短倾向:
  定位: 对自己负责照看的人产生自然的偏护倾向，在人物原有性格底色上做细微流露。
  适用关系:
    - 年长一辈对年幼晚辈
    - 负责带教的前辈对新入门者
  常见表现:
    - 对方受外人数落时，平时往往先开口替对方缓颊圆场
    - 对方私下出了小差错时，有时先顺手帮着把残局拾掇干净，事后再单独提点两句
  例子:
    - 高年级学姐见学弟在课堂上答不上话，下课后自然走过去翻开笔记指点要点。
    - 领班女仆瞧见新人失手打碎茶盏，先默不作声把瓷片扫进簸箕，转过走廊才轻声叮嘱端盘手势。
```

## 四级双轴镜头与开放参考词例

特化与感官文风分两层灯色组织：

1. **顶层常驻蓝灯（第一、二层共用）**：写清 `镜头聚焦`（全景 ↔ 中距 ↔ 近距 ↔ 微观四级平滑缩放、直接承接上轮距离、远宽近细四档颗粒度）以及 `感官聚焦`、`情感聚焦` 的泛用规律，保持零具体部位与零特化词例。
2. **下位条件绿灯（第三、四层按独立专项拆分）**：每个专项独立成条，按「1. 全景 / 2. 中距 / 3. 近距 / 4. 微观」四档颗粒度写出观察规律，具体动作与反应以 `(e.g., ...)` 呈现并注明随人物性格与现场情境自然推进；块末参考词例采用 `维度轴: e.g., 词1, 词2, ... etc.` 的开放刻度，引导模型随现场材质与受力自然延展鲜活表达。

## 角色设定精修要点

- **日常常态、同档位本我差异化与多维表里**：日常块保持干净的常态边界；用人物自身的认知滤镜、欲望执念与随身器物驱动言行，使同一技艺档位的角色生长出截然不同的互动方式，呈现坦率直言、口是心非、硬撑周旋或顺水推舟等多层次表里反应，并在 `roleplay_tips` 点明卡内示例均为气韵采样而非打卡清单。
- **开放互动替代一对一死配对**：把「做动作 A 必触发反应 B」的死配对表，改写为「先定处事原则，再用『平时…有时…一些时候…例如…在特殊情况下…』给出不同心境下的应对示例」。
- **台词纯粹地道**：角色随口双关戏称留在口语台词中；日常语料聚焦眼前生活与熟识对象，保持自然的知情范围与中文语气词。
- **合并抽象近义词，保留具象感官词例**：合并同义的抽象性格词；保留微观文风中区分材质、温度、光泽、声响细微差别的具象感官词例与多切面示例。

## 交付格式

- 按模块输出：**修改位置 → 明确诊断判断（2～3 句） → `before → after` 对照**。
- 涉及设定方向取舍、矛盾来源裁定或【缺口】补充的事项单列在末尾，交由作者拍板。
