# 精炼卡文本（v1.12.1）

总规则：

- 每句话只问一件事：**删掉它，模型玩卡时写出的内容会不会变？** 不会变就删；会变就改写成「条件 → 结果」，写明限度和例外。
- 数值、条件、阈值、限定、例外一条不丢。精炼是去掉不起作用的字，不是缩短篇幅。
- 作者明确指定的单卡偏好或硬性禁令（例：禁某类服饰或配件、锁定某种互动边界）属于已确认特例，原样保留，不拿通用规则删改。
- **只压表达与越界复述，不删已确认模块**：精炼不得擅自删减已确认的模块结构（如角色卡「12+1 模板」中的 `about_xxx` 角色专属机制模块、独立世界书阶段条目 `module` 或阶段事件条目 `event`）。当发现同一内容在多个块（如 `overview`、`acquired`、`persona.key_facts`、`about_xxx`、`roleplay_tips`）重复出现时，按各容器的唯一职责主归属保留核心块并清理其他块的越界复述（例：客观时间线留 `key_facts`、特殊机制留 `about_xxx`、阶段变化留独立世界书阶段条目、`roleplay_tips` 只留纯元指令），禁止为了去重直接把 `about_xxx` 或阶段条目整块删除。
- 只用现成的词：通用概念、成熟流派、圈内高频 tag。没有现成词就写平实的句子，不造词。
- 作者沟通里的比喻、类比、吐槽是给写卡人的解释，只取背后的机制，不进卡。优先级：只用现成概念和圈内通用词、不造词、平实克制说明，高于禁止直接把对话写进卡里；对话里本来就是现成概念、圈内通用词或平实清楚的机制说明时，直接使用，不为了避嫌改写成生僻替代表达或自造新词，需要剥离的只是场外比喻、吐槽和闲聊语气。
- 每条先写上位原则，再往下收窄到条件、表现、边界、例外。
- 精炼结果是提案：改动列成 before → after 交作者确认，没确认的不写成已确认内容。

## 世界书条目

写法：

- 条目名作 key；下一层用条目自己的方面名作 key，值写机制。
- 不套 `name / definition / description` 固定栏。方面名按条目实际情况起，条目之间可以不同。
- 定义只在名字不足以说明它是什么、起什么作用时写一句；复述名字的删。
- 一个方面回答一个问题：什么条件下发生、发生后是什么、到什么程度为止、什么情况下不发生。
- 只讲过去、对当下没有作用的往事删掉；仍影响当下的改写成现在的规矩、禁忌或格局。
- 「强大」「繁荣」「残酷」换成能观察到的结果；换不动就标【缺口】，不编。
- 角色对规则的感受和应对写进角色自己的设定，不进系统条目。
- 同一事实只写一处；已拆成下位专项条目的内容，上位总纲只留名称与一句核心定位。数值互相矛盾时标【缺口】交作者，不自行挑一个。
- 不需要展开的条目写成一行：`条目名: 一句现状`；同类短项超过 5～6 项或合计超过约 400～600 token 时，打包成 1 条下位「同类合集条目」，总纲只留一句模块总括。

示例（自写，按当前卡改写）：

```yaml
区域宵禁:
  定义: 区域每晚执行的通行管制，信号发出后全区域禁止外出。
  信号: 日落后一刻由管理员发出九次信号；恶劣天气提前到日落时发出。
  管制: 信号发出后不得离开区域；区域内走动需携带照明，未携带者由巡逻人员送回住处。
  例外: 医疗与运送应急物资的人员可以外出，外出前需到建筑登记。
```

## 场外比喻不进卡

适用：作者解释机制时用的类比、吐槽、举例（「就像充电宝」「当成提款机」「像吃正餐和喝粥的区别」）。

写法：

- 剥掉比喻，只留背后的机制：谁对谁、什么条件、结果分几档、到哪为止、什么不算。
- 比喻里的现代物件、日常饮食、职业场景不进世界条目、角色设定和文风。模型会把它当成卡内意象，写进正文。
- 只有作者明确说要保留这个说法时才留（例：这是某个角色自己的口头禅），并写进该角色的语言，不进系统条目。
- 不为避开对话原词而改坏表达：只用现成概念和圈内通用词、不造词、平实克制说明，高于禁止直接把对话写进卡里。作者原话里已经用了准确的现成概念、圈内通用 tag 或平实清楚的机制说明时，直接沿用，不为了换词而造新词或绕弯。

示例（自写）：

作者原话：「月光对她们就像充电，满月是快充，新月只能涓涓细流。」

```yaml
# before：比喻原样进卡
月光: 满月是快充，新月是涓涓细流。

# after：只留机制
月光:
  恢复: 照到月光时恢复体力；满月一夜回满，新月几乎不恢复。
  限度: 隔着云层或玻璃减半；白天无效。
```

## 只用现成的词

适用：概念名、方面名、文风标签、角色标签、规则里的说法。

写法：

- 优先用模型语料里已有的词：成熟文学流派、心理学和生理学通用概念、Pixiv 与二创圈高频 tag（例：人外娘、傲娇、病娇、寸止、非人认知偏差）。现成词一次唤醒整片语料；自造词只能靠后文解释，还会被模型当成固定说法反复使用。
- 不拼四字伪成语和复合新词（例：「双核驱动」「饱食回血」「交易博弈」这类）。
- 没有现成词时不另起名字，直接写「什么条件 → 什么结果」。
- 拿不准时去搜：Pixiv、百科或搜索引擎能搜到同义用法的是现成词；只出现在这张卡里的是自造词。
- 作品自己的术语、作者指定保留的词不算自造词。

示例（自写）：

```yaml
# before：自造词
情绪: 冷面回温——被夸时先冷后热。

# after：现成 tag 加条件
情绪: 被夸时先板着脸否认，过一会儿才露出高兴（傲娇）。
```

## 先立上位，再往下收窄

适用：每条规则、每个方面的值。

写法：

- 第一句写最上层的总原则，让模型先定大类；之后用分号、括号或子列表收窄到条件、部位、正反边界、例外。
- 公式：`上位原则 → 中层维度或 tag（下层表现、边界、例外）`。
- 硬结算规则往下写满，概念与氛围型规则停在上位定位：需要精确结算的机制（数值增减、品阶克制、阶段门槛、明确道具效果）往下写清条件、档位、限度与例外；依赖未知感与临场发挥的概念型法则（未知代价、认知异常、禁忌反噬、规则怪谈等）只写上位分类与一句核心定位，应验形式与各人反应留白。
- 不一上来就列具体禁词或具体动作；先写它们归在哪条原则下。

示例（自写）：

```yaml
# before：只有细节，没有上位
描写: 严禁写「眼底闪过一丝」，不要用齿轮、引擎形容心情。

# after：先立原则，再落细节
词汇禁令: 不用自造词和套话；禁用「眼底闪过一丝」（眼神变化写成具体动作）；机械类比喻不进心理描写（不用齿轮、引擎形容心情）。
```

## 写卡备忘不进正文

适用：正文里出现写给写卡人看的取舍说明。模型看不懂它指的是什么，留在正文里只会占位置，还可能被当成设定。

常见的样子：`description_guide: 不用某某的推测`、`按第三卷的说法写`、`以官方设定为准`、`旧稿写错了，已改`、`待作者确认`。

写法：

- 挪到节点的 `## 工序` 段或 `note/`，不导出。
- 备忘背后的结论直接写进正文：资料里有人物猜测和后来揭晓的答案时，正文只写答案，不写「不用那个猜测」。
- 猜测对扮演有用时（这个人物会这样误判），写进该人物自己的节点，标【角色说法】，不进世界条目。

示例（自写）：

```yaml
# before：正文里留着写卡备忘
区域宵禁:
  description_guide: 不用区域负责人的说法，按管理员日志写
  信号: 恶劣天气不改时间。

# after：备忘挪到 ## 工序，正文只留结论
区域宵禁:
  信号: 恶劣天气提前到日落时发出；只有管理员能改信号时间，区域负责人无权下令。
```

## 规则写上位，例子写下位

适用：跨角色生效的倾向、本能、风俗类条目。

写法：

- 条件和反应写上位：类别加关系维度（年长对年幼、指导者对被指导者、非人对人类），不写具体角色名。上位写宽，模型才能套到没列出的组合；以后加入同类的新角色或新物种，也不用改规则。
- 例子写下位：具体身份、场景、动作，标「例子」。每个例子落在不同条件上，不重复同一种组合。例子示范质感，不是照抄的情节。
- 反应写倾向和强度（一丝、有点、会犹豫），写明只微调性格原本的决定，不取代性格；不写必然动作，结果留开放。
- 概念名只在条目里用；正文用自然语言时在条目里给一对错/对写法。这是写给模型的指令，不算写卡备忘。

示例（自写）：

```yaml
护短倾向:
  定义: 对自己负责照看的人会不自觉地偏袒；本人察觉不到，只微调性格原本的决定。
  条件:
    - 年长的一方对年幼的一方
    - 负责指导的一方对被指导的一方
    - 熟悉环境的一方对新来的一方
  反应:
    - 对方被外人指责时，先替对方找理由
    - 对方犯小错时，比平时宽容一点
  例子:
    - 高年级的学姐看到学弟被老师训，下课后去问他哪里没听懂。
    - 负责指导的女仆发现新人打碎了杯子，先把碎片收拾掉，再私下提醒。
  正文写法: 不写「她的护短倾向让她……」，写「她没多想，先把碎片扫进了簸箕」。
```

## 给方向，不锁路径

适用：模块、倾向、文风里持续生效的规则。规则是函数，不是某一次的剧本。

三层：

1. 顶层：一句话定性质或立场（例：「紧张是累积出来的，过程重于结果」）。
2. 中层：条件与强度，写成「当 X → 倾向 Y（限度 / 例外 Z）」；不写动作顺序。
3. 底层描写指导：「当 X 发生时，着重写 Y 的前、中、后变化，不漏 Z」；不写必然触发的固定流程。

特化与感官文风的四层收窄（顶层一二层常驻蓝灯共用，下位三四层按独立职责拆绿灯，互不混写）：

1. 第一层（顶层总控，常驻蓝灯共用）：`镜头聚焦`（焦距在「全景 ↔ 中距 ↔ 近距 ↔ 微观」四级之间双向推拉，每轮直接承接上一轮结束时的距离，不强求退回全景或单轮写满四级；四级对应远宽近细四档独立颗粒度；不得跳过前戏或铺垫直接跨级；由感官聚焦与情感聚焦两条独立维度构成，并写明推进与留白条件）。
2. 第二层（中层上位维度，常驻蓝灯共用）：`感官聚焦`（物理与动作维度，随空间距离与受力状态在四档颗粒度间收窄或拉远）与 `情感聚焦`（心理与话语维度，保持角色日常情感基底，在「场面话」与「心里话」之间按防线切换，不预设发展，不随物理接触自动跳级）。一、二层不含具体部位与具体反应，防止日常走剧情时视野被锁死。
3. 第三层（下位聚焦落点与机制，按独立职责放条件绿灯）：不同职责的专项严禁混进同一个条目，各自作为独立条件绿灯挂在顶层蓝灯下。承接第二层的四级，严格按「1. 全景 / 2. 中距 / 3. 近距 / 4. 微观」四档独立颗粒度（不两两合并）写出规律：镜头越远越宽泛克制（写整体剪影、步态轮廓与远距声响，留白勾起联想），镜头越近越写实密集（展开局部肌理、受力形变、温湿度、气味与深层接触）。具体动作、部位或生理反应一律放进 `(e.g., ...)` 并写明「实际发展按角色性格与实际情况进行推进」，防止模型死盯列出的几项反复复读。
4. 第四层（具体表现，随同主题绿灯加载）：具象原子词池与按四级独立颗粒度一一对照的示例（放最末；纯控制推进节奏的模块可只保留四级示例而不设词池）。词池严禁写成闭合死名单，一律按「维度轴: e.g., 词1, 词2, ... etc.」写成开放的语感刻度，并注明「优先根据现场材质、受力与动作派生更贴切的同类词，禁止把 e.g. 当必选填空题每轮打卡」。

示例（自写）：

```yaml
紧张:
  性质: 紧张是累积的，拖得越久越重。
  变化:
    - 被追问时 → 倾向回避视线、回答变短（在熟人面前减轻）
    - 期限临近时 → 动作变快、出小错（独处时不出现）
  描写: 紧张发生时，着重写开始前的小动作、当中声音和呼吸的变化、结束后松下来的样子；不漏手上的动作。
```

## 角色设定：从上位往下收窄

顺序：`上位概念 → 关键词 → tag → 具体细节`。每层收窄都是写卡时的选择，不按标签的常见联想自动补。

示例（自写）：同一个上位概念，不同的下位方向得到不同角色。

```yaml
互动风格:
  - 雌小鬼：发现别人说错话就抓住不放，用反问让对方自己承认
  - 雌小鬼：主动挑容易激怒对方的话题，看对方什么时候绷不住
  - 雌小鬼：只对认可的人挑衅，用来试探对方能接受自己到什么程度
```

写到能进正文时，写她注意什么、通常往哪个方向反应、有哪些变化：

```yaml
雌小鬼:
  解释: 互动里在意谁占上风；别人露出破绽时，往往拿来取乐。
  语言:
    - 常用反问指出对方刚说错的地方。
  行为:
    - 看对方的反应，决定继续挖苦、改成玩笑，还是先收住。
```

写法：

- **停在上位概念也可以。** 作者只想给范围时不往下写：`喜欢吃水果` 保留了开放性，改成 `夏天吃冰镇西瓜` 就锁定了方向。只有这个细节是角色辨识点时才往下写。
- **参照锚点。** 一时说不清细节、但知道想要的感觉时，可以写 `傲娇：像某作品某角色那样`。参照只提供方向，不搬原角色的经历、能力、口头禅和关系。之后从参照里挑出真正想留的部分，改写成这个角色自己的语言和行为。
- **不写固定流程。** 「每次犯错先反问三句再命令道歉」会被模型照做。改成方向加变化：「常抓住失误反问，按对方反应决定继续、改成玩笑或收住」。
- **近义标签合并，具象感官词池保留。** 性格与抽象概念里的近义词（例：嚣张、顽劣、欺负人都在「雌小鬼」范围里）要合并；每个性格标签都要带来新的语言、行为、选择或关系表现，带不来就合，确实各管一事的拆开写明分工。但微观文风或特化模块里服务于五感白描的具象质感词池（材质、光泽、动态、温度、湿度、气味、拟声等有细微体感差异的词）用于防止模型连续复读同一个词，不按近义词删减。
- **多切面示例保留。** 特化模块里按不同动作、部位或互动切面分别给出的示例，只要每段对应不同切面，就不算同构重复，不合并不删。
- **写不出时只提问。** 作者只给了「喜欢画画」，就问最影响扮演的一个问题（喜欢画画本身还是画画时的安静？画给别人看吗？），一次问一个，或列成缺口。不替作者补一套背景。

## 每层自查

1. 这一层是作者想锁定的方向吗？
2. 有没有带来新的信息？
3. 是否属于上一级概念？
4. 有资料或作者明确意图作依据吗？
5. 和别的标签重复吗？
6. 写成固定流程了吗？
7. 会不会挤掉作者想保留的其他可能？
8. 有没有场外比喻、自造词混进来？
9. 第一句是上位原则吗？

有价值的细节会改变角色的语言、行为、选择、关系、场景反应，或给正文提供可调用的素材；改变不了的删掉。
